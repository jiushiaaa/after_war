先启动本地游戏服务

这个 HTML 需要读取游戏和验收档。在项目的“游戏”目录运行 npm run dev，然后打开 http://127.0.0.1:4180/test.html。

复制到另一台电脑时，请保留整个仓库中的“游戏”和“验证”目录。

这些入口怎么用？
  1. 先选路线或阶段，也可以搜索想看的页面。
  2. 每个节点可选择落地页面，点击“进入体验”会在新标签页打开。
  3. 在顶部点“继续运行”开始游玩；页面跳转不会替你研究、建造或完成事件。
  4. 测试页拥有独立的本地存档与备份，刷新会读取最近自动保存。“重来此节点”创建新的副本，旧测试仍可通过原标签页继续。
  5. 要跨电脑保留测试，请导出文件；目录中的“继续上次测试”仅在这台浏览器有效。

除全新开局外，节点取自真实 UI 推进的验收存档，保留已有选择与损失。阶段体验适合检查玩法与交互，不等同于从新档完整体验或时长验收。

文字、按钮、地图，仍然是原来的游戏。

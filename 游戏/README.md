# 燧人

从一团炉火开始，重建战后文明，最终重返星空。

这是《燧人》地球篇 1.0.2 的可编辑网页游戏工程。基于 A Dark Room 官方源码扩展，保留原生文字、按钮、冷却、库存、事件窗口和渐进解锁。玩家延续的是跨代的共同体，领袖会老去，机构接过职责。

## 已有内容

- 求生、建造、居民岗位与配给，以及带迷雾、背包和真实补给消耗的近郊字符地图。
- 公共服务与工业两条村镇路线，接续万人城市、城市群、跨城物流、就业、迁居与公共预算。
- 地区和国家制度、法律与诉求、贸易、债务、联盟、战争及战后恢复。
- 生物医疗、机械身体、合成人与生态方向，以及八区共同法、航天制造、生命保障与首航。
- 前中后期统一科技图谱、城市用途地图、发展史、档案、文明回顾、配乐和音效。
- 自动保存、夜间模式、简洁重开确认与后台备份。当前游戏内容为简体中文。

本版范围止于地球篇与首航，不包含星际战争或星际旅行。以上是已实现功能范围，不代表所有平台、所有路线的真人体验均已验收。

## 本地运行

使用 Node.js 24，在本目录运行：

```sh
npm run dev
```

然后打开 http://127.0.0.1:4180/ 。正常游戏运行与开发服务无需安装额外依赖。Windows PowerShell 若拦截 npm.ps1，可使用 `npm.cmd run dev`。

更改端口：macOS/Linux 使用 `PORT=4181 npm run dev`；Windows PowerShell 先执行 `$env:PORT=4181`，再运行 `npm.cmd run dev`。开发服务只监听本机。

## 构建

```sh
npm run build
```

构建输出到 `dist/`，包含运行所需的本地脚本、样式与素材，不包含测试工具和验收档。平台播放器在运行时提供 LumiMakerSdk，工程不打包平台 SDK；普通浏览器使用现有本机自动保存。

源码包不含 node_modules、dist、锁文件或本机发布记录。需要分阶段体验的位置记忆、文案导出、语法解析或发布工具时，执行 `npm install --ignore-scripts` 安装 package.json 中声明的公开开发依赖。

## 目录

- `index.html`：正式游戏入口。
- `src/postwar/`：本作规则、界面、存档和平台适配。
- `content/`：科技、事件、叙事与其他内容数据。
- `script/`、`css/`、`lib/`：保留及修改后的 ADR 基础与本地依赖。
- `audio/`、`img/`、`lang/`：本地素材与上游资料；未启用的上游内容不代表本作已开放该玩法或语言。
- `tools/build-game.mjs`：静态包构建工具。
- `tests/`、`testing/`：规则检查和本地分阶段测试工具。

## 完整开发与验收资料

GitHub：https://github.com/jiushiaaa/suiren

当前交付分支为 `feat/a7-polish`。本开源包是游戏工程目录；设计文档、文案编辑基线、长程验收截图和全部历史原始存档位于完整 GitHub 仓库的相邻目录，不随游戏源码包重复分发。

完整的 `npm test`、`/test.html` 分阶段入口及文案基线核验需要这些相邻资料。请拉取整个仓库，保留目录结构，并先读根目录 AGENTS.md 和 HANDOFF.md：

```sh
git clone --branch feat/a7-polish https://github.com/jiushiaaa/suiren.git
cd suiren/游戏
npm install --ignore-scripts
npm test
npm run dev
```

源码包本身可以直接运行正常游戏并构建。“继续上次测试”通过 SDK 的独立本地命名空间记录位置，不使用正式云存档；升级前已打开的测试副本仍可从原地址继续，首次在新版本进入节点后重新记录位置。脚本自然游玩、构造规则测试与真人可用性测试分开记录；完整真人时长以及 Safari、Windows、真手机和读屏体验仍需对应环境验证。

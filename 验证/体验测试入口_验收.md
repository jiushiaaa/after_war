# 独立体验测试入口验收

日期：2026-11-06。用户要求一个可快速进入各阶段和页面的独立HTML。这里验证测试入口、快跳和存档隔离，不把分段导入称为新档自然通关或12—15小时真人验收。

## 使用

在 `游戏` 目录运行 `npm run dev`，打开 `http://127.0.0.1:4180/test.html`（等价 `体验测试.html`）。目录默认推荐11个节点，可展开全部37个节点，按阶段、公共／工业路线、页面与玩法关键词筛选。每节点有来源、当前状况、“试什么”和落地页。

点击进入会在新标签页创建独立测试副本，原始时间点暂停。顶部选择已解锁页面后点“转到”；继续运行后仍是原本规则和合法倍率。可保存、原生导出、另开同节点初始副本。刷新读取本副本最近保存；目录可以继续本浏览器上次测试。

## 实现边界

- `游戏/index.html` 与所有游戏规则模块未改。仅开发服务增加测试路由；`/test-game.html` 将测试适配插入正常HTML副本。普通 `/` 不加载适配。
- 目录使用原生HTML/CSS/JavaScript，无新依赖或UI框架。游戏内部保持原页签、文字、按钮和事件窗口。
- 运行前设置 `postwar-test-v1-节点-随机运行ID` 数据库名；正常 `postwar-local-v1` 不读不写，云SDK不接入。声音偏好也用单独键。每次通过“进入体验”新建副本，已打开的测试不共用存档。
- 服务只允许GET/HEAD读取目录中已知节点，校验真实路径限定于“验证”目录，并核对SHA-256。浏览器再次校验SHA-256，再走完整原生解码／账本校验。不会提供任意本机文件读取或写接口。
- 损坏测试槽、未知节点、校验不符均阻止启动。读取失败不替换为空档，也不覆盖坏内容；可用原有恢复入口读取测试备份。
- 快捷入口调用既有只读视图，不调用玩法动作。它直接对齐原生滑块；普通游戏页签的动画不变。桌面在测试工作台增加内部滚动，城市使用原有内部滚动，保留页头与库存；窄屏适用原响应布局。这个滚动补充只属于测试入口，正式页面长内容的操作体验仍需独立审视。

## 保留限制

- 这是本地开发测试工具。需要完整仓库中的“游戏”和“验证”目录；直接双击HTML会显示启动指引，不绕过浏览器的本地文件读取限制。
- 进入阶段时保留已发生的历史、损失与已完成奖励。要重走更早的选择，应选更早节点或真正新世界，不通过篡改状态假装未完成。
- 自动保存有正常间隔；希望立刻离开前保留操作，可点“保存测试”或导出。测试数据库是当前浏览器本地数据，不随Git同步。
- 节点体验与UI脚本不代替真人可用性或全程时长验收；Windows、Safari完整流程、真手机与读屏未因本轮而变为已测。
- GitHub同步沿用已有授权；不合并main、不部署网站、不发布幻光平台。

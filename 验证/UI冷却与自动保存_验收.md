# 冷却反馈、自动保存与简洁重开（2026-11-07）

## 范围与原因

用户要求恢复生火、添火、采木等动作的原生灰色冷却条；删除右下角手动存档入口，默认自动保存；重开确认只留“重开游戏？”与“是 / 否”。完成后上传幻光现有作品，不修改作者帖子、简介、截图或更新日志。

原计时与冷却条宽度仍正常：改前实测生火后剩余8.3秒、条宽49.8px，但层为z-index:-1且按钮没有独立层叠上下文。上次根页面改为不透明白色后将条遮住。本次按钮增加isolation:isolate，保留文字下方的灰条与原倒计时；悬停/焦点提高按钮层级，保留费用提示的可见性。夜间灰条与禁用文字分别调整为可辨识灰色。没有修改动作收益、冷却时间或存档结构。

删除主菜单“存档”，后台存储、既有槽位与导入校验工具保留兼容。正常本地与云端自动保存不显示成功提示；云写失败提供提示并在10秒后自动重试，即使世界暂停也会重试。重开确认简化，底层仍先完成在途写入、保留两份重开前备份，再进入种子窗口；备份失败不重开。

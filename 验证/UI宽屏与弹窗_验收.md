# 宽屏布局、单色链接与发展史滚动（2026-11-06）

本轮响应实际体验截图：后期页面过窄、导航拥挤、浏览器默认蓝色链接、库存盖住正文，以及发展史弹窗超出屏幕并带动外页滚动。只改呈现与输入处理，不改科技、生产、人口、解锁、计时器或存档规则。

## 实际修改

- 正式入口和独立测试入口共用 `游戏/css/layout.css`。桌面利用全宽，消息、正文、公仓各占独立列；公仓可在自己的列内停留和滚动，不能覆盖正文。无库存时正文使用空余列。
- 原来固定 700px 的横向滑动面板改为同一流式区域切换当前原生页面。科技和城市长页随文档自然滚动，去除其固定宽高、内层裁切和测试入口专用的研究滚动补丁。
- 导航与城市选择器按空间换行并增加间距；数字仍可点开来源，链接用浅色主题 `#222`／暗色主题 `#ddd`，保留下划线和键盘焦点。指标说明也使用主题次要文字色。
- 940—1199px 下村镇设施与岗位区上下排布，避免两个旧绝对定位区域在中等宽度挤在一起；窄屏沿用公仓折叠。
- 发展史和文明回顾窗口桌面宽 760px、高 720px；小屏受可视窗口限制。标题与“合上记录 ×”保留可见，说明和分类按钮共用一个内部滚动区；切分类只重置内部位置。
- 打开事件窗口时锁定背景滚动和焦点；关闭后恢复原滚动位置和入口焦点。发展史支持 Escape；需要决策的新世界设定不能用 Escape 跳过。存档、导入等其他事件沿用同一个有界窗口，不改变按钮结果。
- 原生导入重建视图时清理旧公仓，避免公仓移出原面板后留下重复节点。

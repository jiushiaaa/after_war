# 科技图谱接入验收 · 2026-11-07

## 本轮结果

用户认可三种构图并授权自行选择。本轮采用 A 横向时代图谱、单一详情区，加入少量 B 式未知边界。替换原科技页的长列表与可研究按钮堆叠；没有新增科技、资源、研究队列、国家系统或数值规则。

新增 `游戏/src/postwar/tech-tree.js`、`游戏/css/tech-tree.css`，由现有 `CivilInterface` 接入。原生 `Civilization.research()` 仍是最终条件检查与扣费入口。基础科技读公共／工业路线实际前置和实际折扣；UI 缩放／选择不写入存档。非 DOM 规则测试保留原列表回退。

- 时代横向分区，已掌握／可研究／缺材料／待前置／研究中分别显示。前置路径支持鼠标悬停、键盘焦点及选中高亮。
- 点击工艺后只有一处实际研究动作；展示当前库存与需要材料、前置跳转、试制时长和原有玩法说明。完成项展示当前工艺成本参考，不把它当历史实付账。
- 拖动空白、滚轮或按钮缩放、迷你图、定位研究、已知工艺选择列表；窄屏原生触摸平移，详情下排且内部可滚动。不宣称支持双指缩放。
- 未发现工艺最多显示 3 个问号边界，不预告隐藏名称、说明、数量和成本；基础图谱全部掌握且先进社会已经接手时，默认折叠收纳。
- 保留先进社会、航天工作台及其不同研究机制，没有为了统一呈现修改它们的账本。

# 夜间模式、安全重开与平台背景（2026-11-07）

## 范围

按用户最新决定先不制作英文版，也不展示无效语言入口。本轮处理主题/背景/重开/云端成功提示，以及用户追加的整个发展史精简与正序；保留ADR文字按钮、现有玩法/渐进解锁/Gemini中文正文和原始导出。版本1.0.1，续发既有作品；不提交公开社区帖子。

## 原因与实现

平台实际iframe的html与body背景均为`rgba(0, 0, 0, 0)`，header为白色。透明背景透出了宿主灰色。现在根与body日间均为#fff，正文#222；夜间背景#272823、正文#ddd，页头/菜单/弹窗/地图沿用原暗色表。本机IndexedDB独立偏好键保存主题，不写State或平台云档；旧存档主题字段不作迁移或改写。

右下角新增“重开”和“夜间模式／日间模式”，窄屏换排。原存档窗口里的重复“切换明暗”移除。新世界确认前依旧停钟、不写档。

重开前必须先成功备份；等在途云写入和本地队列完成再转换世界，禁用确认按钮防止重复动作。独立备份轮换保留最近两次，不占三个本地槽。备份失败恢复原暂停状态/世界，初始化失败停钟且禁止自动写入。读回时先走原生账本校验，当前世界也备份；本地原槽保持只读，玩家可另槽保存。

成功云存档不再输出“云端已保存”，静态初始提示也为空；保存失败提示保留。本地明确保存与错误提示仍在。

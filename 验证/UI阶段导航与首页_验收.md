# 阶段导航、留白首页与即时体验反馈

2026-11-06，分支 `feat/a7-polish`。本轮是界面与启动流程优化，没有增加国家玩法、资源或计时门槛。

## 实际改动

- 开局保持已有的渐进页签。达到真实城市后，原镇、街区、周边聚居地及地方建设进入原生折叠“地方事务”；未交接的工区仍留在主导航。城市群之后，无外出队伍时将旧公路收纳，有队伍或旅程时保持主入口。收纳只移动原有控件，不替玩家完成委托或删除操作。
- 主城市页随实际阶段显示“城域／城市群／地区与国家”。现有后期样本的主导航为地区与国家、科技、法律与诉求，加一个地方事务折叠。展开选择后自动收起，键盘焦点回到折叠标题；定时刷新不强行关闭正在阅读的折叠。
- 城市、地区概况、城际协作、共同事务统一用“查看范围”选择框。仅列已接触的城市；原两套城市按钮、单独地区链接、共同事务往返按钮移除。街区页的“查看住房／安排迁居”与同页分类重复，也已移除。科技完成后的具体“去建”、短缺诊断与下一步定位保留，因为它们会定位实际事项。
- 普通入口先显示白底、居中的唯一按钮。无存档是“开始游戏”，有完整存档是“继续游戏”。开始后才初始化世界并打开原生种子设定；确认按钮按用户反馈改为“进入世界”。设定期间全部模拟时钟暂停，确认后才显示游戏、开始运行与保存。读取失败显示原有恢复入口，不把坏档替换成空档。
- 已有节点的独立测试页仍直接进入所选阶段；测试目录的新档则经过真实首页。测试暂停、存储隔离、原生导入以及本地三槽继续保留。
- 研究按钮按文字宽度排版，“半导体与控制器”不再被原生100px行内宽度挤成两行。
- 左侧继续将新消息放在上面。开场先写撤离记忆，再写推开舱盖，随后写房间寒冷和火堆熄灭；从底部向上读，剧情顺序一致。每段内部仍正常从上往下阅读；已有存档继续时不重复开场。

通过本地专用无头Chrome，以CDP发送真实鼠标／键盘输入；读取状态只做观察，没有注入资源、人口、时间或进度。这是界面验证，不是重新自然通关或真人可用性验收。

2. 1280暗色导航检查。现有原生明暗切换不受影响。
3. 三种宽度的新首页均只有一个居中按钮。点击前没有State或CivilClock；种子窗口等待不推进时钟。Escape不能跳过，负数种子拒绝，7417可确认。独立测试页确认后保留测试暂停。

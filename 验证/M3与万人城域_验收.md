# M3 两路线、世界人口底账与万人城域验收

2026-11-03。按用户批准的设计 74 推进。本轮范围为 A0 的 M3 收尾、A1 底账核心、A2 万人城域首个可玩闭环；没有增加国家外交菜单。

## 证据口径

- 自然线：独立 Chrome 配置从新游戏开始，仅发送真实鼠标、键盘输入，通过正常倍率、原生选择和原生存档推进。没有给游戏注入 State、人口、资源、模拟时间或解锁标记。
- 204/205 在引入新世界规则前分别新建，具有 M3 方针标记，保留旧人口规则；206 是启用 `ruleset: 2` 后的第三份新游戏，不是把前两档放大或改标记。
- 脚本知道规则，期间修过点击定位、翻页等待和岗位安排；包括通过原生导出/导入刷新界面的检查点。模拟年份与墙钟时长包含这些等待，不能据此判断哪条路线绝对更快，也不能当作新玩家盲测。
- 公共线一次手动诊断使用相同的真实点击，增派一名医护、扩建一座诊疗站，没有修改底层状态。其余输入见 `M3/*真实输入.ndjson` 与工具源代码。
- 构造场景、独立长跑与自然档分开。`工具/构造城域基线.cjs` 生成的 11444 人城市明确是构造测试，截图位于 `A1-A2/`，不是自然到城的证据。

## UI 验证

- 保留原生 ADR 页面、字体、边框、地点、库存和左侧记录。新增城域按小镇与测绘解锁，再分概况、普查、生产与预算、公共工程、运输。
- 初版连线图收到用户“太丑”的反馈后已替换为山谷字符地图。片区标记可直接选择；地形固定，道路与普查读取当前游戏事实。地图选择后水务/优先级动作确实作用于所选片区。
- 390px 地图与页面没有横向溢出；桌面内滚动不再压住库存列。原镇建筑清单可折叠，展开/收起均不与库存重叠。
- 修复原生导入中注册工种触发嵌套更新、生成两份村镇建筑清单的问题。科技滑动页恢复 700px 宽度；窄屏保持随视口变化。
- 暂停阻止近郊出发、移动和返回；生产/旅程继续使用原共享时钟。暂停不写进存档，重载自动恢复正常计时。
- 浏览器检查脚本：`工具/城域交互检查.mjs`。真机触控、Safari、读屏和完全不知攻略的新玩家仍未验收。

## 规则与长期检查

`游戏/tests/census-city.test.cjs` 覆盖人口守恒、来源透支、旧档隔离、已存在片区的生产、付费工程、接纳不增人、生产方法、用水中断、运单一次交付、材料账、群体上限与严格导入。旧年度游标不能重新结算出生。

套件的 100 年检查和 `城域人口长期复核.cjs` 的 300 年检查仅运行片区与底账；300 年末三个片区分别 3740 / 4620 / 3300 人、健康 100、稳定服务 600 秒，每地 160 组，世界总量 1237207080，人口与物资账校验通过。完整适配器另有构造城市与短期续跑。这些不是完整新档的数百年自然游玩，也不能证明所有政策永远稳定。公共就业先按岗位与服务保底分配；技能训练、工资竞争、家庭预算和私人资产不在本轮完成范围。

本轮收尾全量回归 **823/823**（614.094秒），失败/跳过0。随后补验第二处水务释放岗位和最终 UI 文案，定向 **44/44** 通过；浏览器地图选择、窄屏、原镇建筑折叠与原生导入检查通过。日志见 `A1-A2/完整回归823.txt`、`A1-A2/定向回归44.txt` 和交互 `result.json`。

复核命令：在 `游戏/` 执行 `npm test`；在根目录执行 `node 验证/M3与万人城域存档复核.cjs`、`node 验证/城域人口长期复核.cjs`。自然输入工具位于 `验证/工具/`。

## 下一轮优先级

1. 用最新新世界自然档继续城市层的经营差异、劳力技能与委托；让原镇的手动岗位逐步交给机构，保留真实应急调度。
2. 复核工业路线接入新规则城市，以及生产方法、储备优先级、地方间调运在实际短缺下的取舍；当前自然路线不能代替全部组合。
3. 在这些事实基础上进入 A3 的城市群分工、物流和有限社会诉求。不重新从 138 扩国家功能，也不把原 131 首航当作新世界已经通关。

# 前中后期统一科技图谱验收 · 2026-11-07

## 交付范围

在既有横向图谱中接入先进社会 13 项、地球与航天 5 项科技。时代顺序为早期、中期、后期基础工艺、先进社会、地球与航天；同一画布、查找列表、详情和定位操作贯通。各系统保留实际账本和研究班组，未增加科技、改费率或迁移存档。

- `tech-sources.js` 只负责呈现适配：基础从原镇公仓扣费；先进社会和航天从共同体仓扣费，各有研究任务。后两者共享实际居民与能源，仍调用原 `CivilFuture.act` / `CivilEarth.act` 写入原账本。
- 尚未建立共同体／全球议约时，不展示对应研究表；之后只显示已掌握、进行中和实际前置达成的科技，远处最多 3 个匿名问号。隐藏名称、成本与后续数量不进入图谱模型。
- 连线仅来自真实前置；没有为了把三个系统连成一条线而伪造依赖。普通生态路线可以走向航天，不强制先机械化或合成人社会。
- 单一详情展示材料来源、当下库存、立项成本、有效研究工时。持续工位／电力／耗材放入折叠明细，研究中默认展开；缺料、缺实验楼、同班组忙碌各有说明。
- 多班组同时研究时，“定位研究（2）”依次定位，进度读取各自任务。不同班组可并行，不把三份任务错误合并成一条队列。
- 删除共同体下拉框的重复“研究方向”和重复能力清单；地球工作台“测绘与航天研究”改为“航天设施”，保留实付建设。持续服务、制造配方、生产委托、身体采纳、法律、航天任务与发展史仍在原处。
- 图谱放在工作台前。只有地球结局已达成且当前图谱真正全部完成时才整体收纳；仍有可研究的可选路线时保持可见。

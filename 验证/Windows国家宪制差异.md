# Windows 国家宪制差异与真实改革

2026-11-02，接续铁路17原始自然档。实现范围见设计46；用户尚未说“收工交接”，本次只是持续开发里程碑。

## 实际实现

- 成文宪章和惯例盟约都能从已登记城市群成立国家。议约仍由三城分别实付，不送库存、人口或认可。
- 成文连续筹备600秒；惯例900秒。改换宪制重新累计同一制度的连续履约，保留此前各城已付议约费用。
- 四种宪制/中央地方组合有实际独立仓库成本。惯例较少知识、较多木料和工具；认可正常+0.125/失效-1.25，协调中央+1/地方+2。成文维持+0.25/-1，协调+2/+4。
- 每笔新国家记录包含当轮宪制；旧账缺少字段时按原成文规则校验，不改写旧存档。成立时的四轴历史保留。改革后的协调需新制度的实际已付服务，不凭改选即时发放。
- 原生权力约束窗口在城市群后显示国家职责比较，早期仍只显示早期制度。保留现制沿用既有退款与政治回执。

## 剩余边界

这是现有国家闭环的宪制差异，不是完整政治模拟。仍没有军队/战争、宏观区整合、全国交通、全球统一与首航。下一步继续国家阶段的纵向玩法，不回到前期小修；自然主线21保留供养、公约和铁路，可用于后续开发。

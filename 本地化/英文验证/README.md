# 英文小批验证（2026-11-07）

## 实际结果

通过用户授权的 timicc 兼容接口，使用 gpt-5.6-luna 完成 37 条小样，涵盖开局、资源、城市、先进社会、地球和动态人口／运输消息。一次付费生成，接口返回 usage：输入1555、输出1098、合计2653 tokens；代理费率未核实，不能把 tokens 声称为实际人民币费用。

- `sample-input.json`：仅文案与必要上下文，不含存档、身份信息或密钥。
- `sample-response.json`：保留原始返回，供追溯。
- `sample-normalized.json`：仅移除完整外层 `<escape>…</escape>` 后严格JSON解析。不是任意截取大括号或修补截断JSON。
- `sample-reviewed.json`：逐条审阅后的37条候选，不是已上线英文版。

37个ID与顺序、占位符多重集合检查通过。但直接机器翻译尚未达到全游上线门槛：几根干柴被写成几捆；车队被写成列车；人口动态句存在单复数问题；工具消耗被译成磨损。已在审阅稿修正六条。资源／数量语义不能仅靠数字正则验证。

## 网络与凭据

系统代理为本机7897端口，但终端没有代理环境变量。请求显式指定HTTP代理且清空no_proxy，不设直连回退，TLS验证保持。两项独立代理出口检查一致为新加坡；关闭目标代理端口时请求失败。没有测试直连出口，也不承诺匿名或无法被账号关联。密钥仅从用户指定文件在内存读取，经curl标准输入传头；不写源代码、参数、日志或发布包。这里不记录完整出口IP。

## 全游接续门槛

1. 独立导出当前显示文案到新目录，不覆盖中文Gemini基线；排除状态键、旧兼容source键和开发诊断。
2. 固定术语与单位：wood/sticks、convoy、synthetic person、Hearth City、Echo。动态名词／年龄／人口消息需单数、复数、零值测试，不把中文片段直接插入英文模板。
3. 批次按文件／功能分组并去重，结果断点缓存；每批严格检查ID、占位符、数值、标记、否定和资源含义，错误条目隔离，失败不无限重试。
4. 费用上限与实际模型费率尚未确认，不进行无上限全量付费调用。后续优先完成只作用于显示层的本地化接口，世界账本继续使用原始标识。
5. 在独立英文预览中检查新开局、城市、国家、先进社会、航天、动态提示和窄屏；中英文切换不改变存档状态。样本审阅不等于全游英文验收。

本轮没有把未完成的语言切换放进正式中文版，没有修改中文叙事或旧存档。

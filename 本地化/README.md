# 燧人英文版

源文 `英文全稿/source.json`：8864条独立文本（含88条旧自然档回顾兼容模板）；UI补充22条。当前编译词条8886条。中文源码和Gemini基线保留；English只改呈现，不改存档键、世界或账本。

## 验证与构建

在仓库根运行：

```sh
python3 -I 本地化/tools/compile.py
node 本地化/tools/check-render.cjs
node --test 游戏/tests/english.test.cjs
npm --prefix 游戏 run build
```

完整编译缺译或结构不合格时拒绝写入生产词库。`--partial`只用于本机预览，不能发布。`batch-inputs.json`是不可重排的任务清单，已有有效缓存跳过；增量只能追加新批。`reviewed-overrides.json`记录语义校正，`numeric-reviewed.json`仅对完全相同的源/目标批准汉字数字等价，不能泛化豁免。旧档只增加显示兼容，不覆写历史。

`src/postwar/english.js`在DOM呈现层替换已知文本和模板，保存中文原文以便切回；输入框、存档载荷、资源键不翻译。未知复合文本保留原文，避免半截错译。语言本机记忆；`?lang=en`英文直达，`?lang=zh`中文直达。初始首页仍只显示开始按钮。

## 模型与用量

用户授权timicc首个密钥；主体gpt-5.6-luna，失败批和兼容补译gpt-6.1-sol。密钥只从本机授权文件读入内存，以curl标准输入传递；不写入脚本、仓库、构建或日志。请求强制HTTP代理127.0.0.1:7897、TLS校验，无直连重试。代理出口不等于匿名，服务商仍可通过账号和密钥关联请求。

全量返回1706840tokens（输入1327222，输出379618），小样另2653。用量含已返回的重试；超时未返回用量可能另有计费，无法据此给出实际费用。运行游戏不使用这些凭据、无需后端、不产生翻译API费用。

## 证据与限制

完整1192规则测试通过，最终17专项通过；8886条模板渲染0问题。检查公共万人城、工业城市/国家/先进社会/科技/历史/首航，390窄屏、中文恢复。首航回顾旧句238次出现由88条兼容模板覆盖。属于AI翻译加关键规则和UI抽查；没有母语编辑逐句校对，也没有新一轮英文全程13小时真人或实机移动端验收。

# 地球篇完整科技树

科技是恢复知识、试制设备和维持量产三层过程。拾到外骨骼不等于拥有外骨骼工厂，解读图纸不等于有稳定电力。下表构成地球篇完整依赖骨架；已接入的村镇节点与数值见设计09，采矿至发电的实际数值见设计12。其余节点仍为待实现规格，是否经过真实游玩见设计08。

## 研究规则

每个节点记录 `id、前置科技、发现条件、试制成本、时间、运行投入、解锁结果`。必需研究通过主线保证资料可得；支线遗物可降低试制成本或提供独特能力。理论资料永久保存，设备需要修复，量产还需要厂房、岗位、能源和运输。换研究不退还已经消耗的材料，暂停保留剩余工时。

资源投入分等级：村级以木料/废料/食物为主，小镇级增加铁/煤/工具，城市级增加钢/零件/电力/药品，国家级增加电子件/稀有材料/燃料。基础成本由等级基数乘节点复杂度（1、1.5、2）形成，实际数字在对应阶段落地时平衡；不伪称尚无生产模型的数值已通过验收。

| 等级 | 单项试制时长初稿 | 瓶颈 |
| --- | --- | --- |
| S0 求生 | 行动和修建，无抽象科研点 | 燃料、温度、工匠 |
| S1 村落 | 120至300模拟秒 | 废料、食物盈余、技术岗位 |
| S2 小镇 | 300至480秒 | 工具、矿产、熟练工与电力 |

| S4 国家 | 720至900秒 | 跨区材料链、科研组织、能源 |
| S5 地球 | 900至1200秒 | 全球产业、先进设备与公共投资 |

## 路线和遗物管理

农业公共卫生路线更稳、更能接纳人口；工业军备路线扩张快但吃维护、污染与制度成本；贸易联合路线利用互补产业减少自给压力，但受外交与运力限制。三路均需基础供养与行政，最终可互相补齐，不设置永久不能生产食物的研究锁。

遗物单独记录完整度、兼容性、能源规格、已识别风险和原型数量。每一件既可以使用、拆解或保存研究；选择写进左侧记录，重要取舍弹窗。稀有唯一物品拆解后仍有昂贵自主研发替代，避免误点锁死主线。装备穿戴主要体现在专业队伍和探索提示，不出现开局人物装备面板。

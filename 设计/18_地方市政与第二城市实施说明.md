# 地方市政与第二城市实施说明

**状态：本轮模块已实现并有专项测试，完整自然游玩由根代理另行记录。** 当前范围是第一座 home 城市之后，原有河谷、铁轨镇、高地可以逐项建造地方设施并成长为地方城市。本说明不把三个城市、3000人、铁路、电网联网、货币财政或建国算作已完成。

## 1 议约与唯一账本

首先需要 home 已登记城市、完成 urbanworks；当地已兑现 publicWorks 且处于 associated/integrated。原生“市政”地点出现地方代表按钮，玩家选择地方并主动议约，一次实际支付 home 20知识。议约不会增加当地人口、材料或机器。

地区节点 `c.regions.nodes[id]` 继续唯一拥有 cohorts、population、stores、workers、health。新增 `c.municipal.nodes[id]` 只存基础容量、已建设施、施工项目与经济/政治证据；home 不再经营一套重复市政经济。首次议约锁定当地原住房 `CivilRegionContent[id].population+12` 以及当下实际岗位作为基础容量。之后旧生产配方原样保留，新岗位必须来自付材料建成的设施，不能把旧手工机棚直接重命名成免费电气工厂。

`has(s,id)` 表示已经议约的合法自有节点；`canAccept(s,id)` 再要求它仍 associated/integrated。两者均不因暂时缺粮或缺床抹掉既有目的地。已发车的乘员始终保留自己的 target；临时不合格则候床或返回来源。变异居民使用相同旅费、供养与接纳接口。

## 2 真实施工与运输

每个地方同时只筹建一个项目，使用单调递增 projectId。工程先处于 supplying，材料逐批由 home 的既有货车运来；64运量是真实限制，沿用既有路线两名运输工、运期、维护和路阻/返航。工程与贸易交替发车，避免长期用工程货把高地的口粮合同挤掉。材料欠缺时可以先送付得起的部分，不能负库存，也不能无视货物仍在路上而重复下单。

材料抵达项目独立 buffer，不是可拿去吃饭或交易的地方库存。最后一批到达后，整套成本只扣一次，项目转 building；当地需要2名实际成年 builder，每模拟秒推进1秒。健康不足30、劳动力退休/短缺或关系不再允许共同工程时暂停，已支付材料和工期保留。完成才增加设施容量，之后才允许下一项。没有取消/换项目接口，避免丢弃或重复兑现尚在途的物料。

`receiveCargo` 要求真实队列中的同一个 cargo 对象、相同 route/projectId、outbound、moving、remaining0，并以 shipmentId 留收货回执；重复调用、复制货单、旧工程编号均不能再入库。完成工程后仍在路上的空车可合法返航，即使已筹办下一工程也不抹掉历史项目记录。

## 4 地方供养、工业与电力

每10秒按实际居民和已付费容量自动分配地方岗位。优先保口粮、医疗、施工与维护，再安排教学和工业；总岗位不超过当地18–64岁实际人数。岗位上限由固定基础容量＋完工设施推导，任何时候都没有免费劳工。

旧农作每人0.8粮，新增田片每人消耗0.01工具产1.4粮。制器消耗0.2木和0.6废料产0.25工具；医护消耗0.2粮和0.1废料产0.15药，高地原有医护继续需要0.01煤；教师消耗0.1木，每人覆盖20儿童并产0.2知识。旧铁轨机棚沿用废料/煤/铁/工具的实际投入配方，不计入新矿冶链的完成证据。

新矿工每人用0.03工具产1.2矿；煤工用0.03工具产1煤；冶炼用1.2矿、0.6煤、0.01工具产0.6铁。新机械工用0.5铁、0.2废料、0.01工具，手动产0.3零件，实际用2电时产0.5。电工用0.6煤、0.02零件产生当轮4电容量；每轮重算、未用电力丢弃，不存在可囤积电库存，也不能使用 home 的电力。除尘消耗1本地电、0.2木、0.01零件；其耗电不算“生产用电”。

居民每10秒消耗加权人口×0.12粮，儿童权重2/3；治疗消耗实际人口×0.01药。缺投入减少实际批次，缺粮/药影响健康；冶炼发电产生烟尘，除尘实际运行才削减。供养证据还保守扣除当前贸易合同的地方出口均摊，不把尚未抵达的 home 进口算作本地生产。新设施的维护材料也需要贸易或实际本地生产，建筑完工不会另赠启动库存。

## 5 接纳与代际

Urban 独占所有来源/目的地的两组车队、交通岗位、旅费与乘员年更。目的地变为某个已议约地方时，Origins/旧480名册只扣一次，真实年龄组到达后只加入该地方，home 人口不变；返乡归原 source，不归出发支付仓。地方入境后的生育、年龄推进和离世仍归 Regions。

`serviceCheck(s,id,cohorts)` 接收“该目标已在途＋本批”的候选年龄组，克隆预测一次实际地方经济。它要求当地田片、诊疗、学舍已建，健康至少60、120秒粮食储备、实际教师覆盖孩子、当轮医护足够治疗、扣除出口后的粮药不亏以及行政服务可用。人口床位由 Urban 统一检查，避免到达时重复计算当前队伍的预留；地方出生使用 Municipal.capacity 并减去 Urban.reservedBeds(s,id)。

`admit` 只提交真实年龄组并更新地方人口和岗位，不重新收费，也不在来源已记抵达后追加新的服务拒绝条件。服务检查在 Urban 的提交前完成。即时供养变化不会让途中居民凭空消失，原先支付的旅费也不会因返乡退还。

## 6 镇制和地方城市的证据

80名真实当地居民，实际田片/诊疗/学舍，持续供养与教学、健康至少60、行政服务与近期可通行已兑现的贸易路线，累计连续180秒后才出现镇制登记事件。失败会清零当前稳定计时，已登记镇制保留；登记本身不发资源或人口。

400名真实当地居民再稳定300秒，要求已登记镇制、健康至少70、烟尘低于40、新矿煤冶炼机械四段都实际产出、至少4本地生产用电、120秒粮食储备及当地40工具/40铁/20零件。除尘用电不充当生产，旧铁轨机棚不能单独冒充新产业链。条件改变后，事件确认会重新检查，不用过期结果授予城市。

这些事件只登记该地方 city，不设置 cityCluster 或国家标志。人口下降或工业断供不删除已登记城市，但持续证据必须重新恢复才能支持后续发展。

## 7 接口和持久字段

```js
CivilMunicipal.init(s)
CivilMunicipal.has(s,id) / eligible(s,id) / activate(s,id)
CivilMunicipal.canAccept(s,id) / capacity(s,id) / jobCapacity(s,id)
CivilMunicipal.planWorkers(s,id)       // n.workers 唯一归仓，按本地成人与容量
CivilMunicipal.settleNode(s,id)        // 替代该节点旧经济，home flow={}
CivilMunicipal.tick(s)                // 实际施工；不再次生产或给旅客加年龄
CivilMunicipal.forecast(s,id,cohorts)  // 克隆，返回 copy/deltas/food/medicine/
                                      // education/treatment/productivePower/industry/reason
CivilMunicipal.serviceCheck(s,id,cohorts) // null或具体阻断原因
CivilMunicipal.foodReserve(s,id,cohorts)  // 120秒当地真实粮需求
CivilMunicipal.admit(s,id,cohorts)        // 仅地方入册，返回人数
CivilMunicipal.startProject(s,id,type)
CivilMunicipal.nextCargo(s,id,capacity)  // 只读 {projectId,cargo}|null
CivilMunicipal.receiveCargo(s,id,cargo,projectId) // 首次真实收货boolean
CivilMunicipal.validShipment(s,p)
CivilMunicipal.validate(s)/refresh()/reset()/event(id,done)/nextEvent(s)
```

`c.municipal={schema:1,nodes:{}}`。节点保存 agreedAt、baseHousing、baseWorkers、buildings、nextProject、project、completed、town/city、稳定秒数、pollution、power、economy。项目保存 id/type/status/required/buffer/remaining/receipts；completed 保存项目 id/type/completedAt，设施数量必须与完工记录逐项一致。货车字段用 purpose='municipal'、projectId，既有 Region shipment 的源/目标/状态/容量约束仍然有效。

合法旧档缺 municipal 才初始化空模块。显式null/false、虚增设施但无完工记录、超cap岗位、错误物料buffer、重复项目或超发电负载均拒绝。以新版完成记录恢复后不会重授设施；基础人口仓库不被模块初始化覆盖。

## 8 当前验证与未完成项

模块专项13项测试已通过，覆盖议约及一次性付款、无材料/人口授予、64货真实分批、报价纯度、接收幂等、施工退休暂停、老项目空返、逐步付费住房、克隆预测、旧生产单次结算、真实矿冶电力与断供、镇制与城市门槛、损坏存档拒绝。完整城市经济测试里的80/400居民是明确的容量/经济 fixture；设施仍通过付费货单和实际施工形成，不能把该fixture称为自然迁入400人。另一个长期回归以0–79岁每岁5人共400人为初始名册，运行完整60000模拟秒（100年）的地方生产、真实贸易和年度出生/衰老，不补人口或库存；居民增长至fixture的480床上限，累计出生660，最低成年劳力235、最低健康90，工具、粮、药储备保持，末尾仍有矿煤冶炼机械产出与至少4生产用电。新增三地区legacy容量校验拒绝伪造旧制器、矿工和电工，农医岗位也不能超过未扩建阶段可达上限。

根代理正在把旧自然档的河谷实际议约、建田片/诊疗/学舍、接纳真实来源居民作为新检查点。正式自然验收、页面截图与全套回归结果另存工作记录。区域电网、钢铁化工、铁路财政、民间仓/货币/税收、3000人城市群仍未实现；本轮没有展示这些内容的假按钮。

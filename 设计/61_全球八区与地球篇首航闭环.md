# 全球八区与地球篇首航闭环

2026-11-02。承接设计60。本文描述本轮实现规格；自然验收到达位置以HANDOFF最新冻结档为准，不能把独立适配器测试当作自然通关。

## 主线顺序

北陆、东陆、西陆接纳 → 近地轨道测绘 → 远洋运输 / 生态修复 / 航天制造 → 剩余五区 → 闭环生命保障 → 地球共同法 → 实物试验与无人先遣发射。

三块初始大陆对应的城市联盟作为其大区的议约主体。其余五区是各自多个城市、港口、绿洲或避难所的联合议约主体。八区是地球篇的战略地图抽象，不是把八个村庄称为全球；目前没有逐城生产、逐户市场和完整大区人口代际模拟。各区公开名册与公共预算独立，不把283000名宏观居民加入炉火城人口、岗位或仓库。

## 渐进入口

- 初始三个网络仍由现有三个聚居圈实际接纳后开放。
- 只有北陆、东陆、西陆全部接纳才出现轨道测绘，不能以其他三个区域替代。
- 轨道测绘完成后，国家远域记录中才出现其余五区，同时议事屋出现“地球共同法与航天”。
- 新地区还需要实付建成“远洋与全地形勤务船队”，与原勤务站共用六名现有居民和单项行程；保存船队资产编号及出发时间，不免费生成舰船或居民。
- 航天制造与生态修复从轨道测绘分支展开，生命保障在这两者之后。仍使用原科技页、街区加工分类、聚落岗位及ADR事件窗口。

倍率仍合并在原单一入口：轨道测绘解锁32×，地球共同法解锁64×，不会替玩家自动切换。生产、年龄、施工与运输共用时钟；不添加离线补时。

## 航天生产与验证

- 航天装配工：每人每10秒耗6电、钢1、精密件0.5、电子件0.3，基础产出0.1航天组件。
- 生命保障技师：每人每10秒耗4电、化学品0.5、药品0.2、玻璃0.3、精密件0.2，基础产出0.1生命保障组件。
- 车间沿用已有工业产出系数、实际供电与扣料，断电不出货。
- 发射测控场按实付材料、两名营建工和1200秒施工建成，提供四个测控岗位，不增加人口。
- 生命保障地面试验需组件6+航天4，连续300秒；无人轨道验证需航天16+生命4，连续600秒；最后先遣发射准备需航天24+生命12+机器人8，连续600秒。
- 每轮试验与准备都另需四名实际测控人员、12单位本城剩余电力和维护材料。与加工共用同一个电力池；暂停机器人/组件装配可释放电力，风电不能被当作稳定满功率。
- 断电、欠供、缺员或行政失效会清零连续运行计时，不退已经消耗的组件，恢复条件后同一项目继续验证，不重复发奖励。

# 先进材料与共用电力实装规则

**状态：先进材料模块及工业接线已实现，专项回归通过；自然游玩与服务整合由根代理另行记录。** 本文只记录矿物料、化学品、钢、玻璃及相应动力、维护路径。无线电、导线、铁路、区域电网、城市群与国家不在本模块范围。水务、制药和高密住区由独立 Services 切片负责，不能把本文件的材料回归当成千人城市验收。

## 1 渐进解锁

新增资源仅 `minerals / chemicals / steel / glass`，中文为矿物料、基础化学品、钢材、玻璃。首次合法生产留在 `c.advanced.made`，消耗库存后仍保留这项技艺；读档不以当前仓库数量反推“已经生产”。

- 基础化工 chemistry：已有 furnace、sanitation，home 曾登记首城且仍有旧冶炼炉。无需当前人口仍为400。研究实际支付知识90、铁30、煤30、零件12，480秒。
- 研究完成先开放矿物采集场。实际产出矿物料后，基础化工间才开放。
- 实际制出化学品后，才开放炼钢研究、玻璃窑、公用电站、矿煤扩建和净化设施各自满足的前置。
- 炼钢 steel：furnace、chemistry、曾实际制出化学品；支付知识110、铁50、化学品12、工具16，480秒。完成后可建炼钢炉。

UI 仍是现有工区的原生建造按钮、设施数量和工人分配，不增加先进材料总控页。未生产上游材料时，不把所有工厂同时排给玩家。

## 3 每10秒真实配方

下表产量为正常条件下每个实际运行岗位的基础量；已有社会、配给、饥饿和健康影响继续作用，材料投入不因减产凭空返还。缺料只完成付得起的完整岗位批次，库存不为负。

| 工序 | 付电时投入和产出 | 无电/剩余电不足时 |
| --- | --- | --- |
| 矿物采集 | 工具0.03 → 矿物料1.2；不耗电 | 同配方 |
| 化工 | 矿物料0.4、煤0.2、工具0.01、2电 → 化学品0.4 | 矿物料0.4、煤0.3、工具0.01 → 化学品0.12 |
| 炼钢 | 铁1.2、煤0.5、化学品0.05、工具0.01、2电 → 钢0.6 | 铁1.2、煤0.7、化学品0.05、工具0.01 → 钢0.3 |
| 玻璃 | 矿物料0.6、煤0.25、1电 → 玻璃0.5 | 矿物料0.6、煤0.4 → 玻璃0.2 |
| 公用电站值守 | 煤0.9、零件0.03 → 当轮10电容量 | 缺燃料/维护件不发电 |
| 工区净化 | 每设施化学品0.03、木0.2、零件0.02、2电 → 烟尘降低0.8 | 无电或缺料不运行 |

化工每实际批次增加烟尘0.035，炼钢0.06，玻璃0.025，公用发电0.04。旧炉、旧电站和旧烟尘处理保持原有规则。新增净化设施提供付费的污染处理扩展，避免一座旧设备成为无法补救的扩产上限。

原手工制器、矿煤开采、旧机械坊手动零件生产继续存在。黑启动不要求先有钢或新电网：手动机械补维护件，采煤补燃料；化工、钢与玻璃可以煤热慢速生产。没有免费发放的备用零件或起始电池。

## 4 电力只能用一次

Industry.settle 仍是 home 的唯一工业结算入口。先运行基础采矿/采煤/冶炼，然后旧小电站与公用电站各付一次燃料和维护；合计形成同一个即时电力预算。消费顺序为：

1. Services 公共供养工序（若模块已接入）。
2. 旧烟尘处理、先进净化设施。
3. 化工、炼钢、玻璃。
4. 旧机械作坊；分不到电的岗位继续原手动工序。

所有模块只能使用传入的 `powerAvailable`，返回实际 used，调用处只扣一次余量。付不起原料的岗位不占实际电力，其余工序仍能使用剩余容量。未用电力在下一轮丢弃，不写入 stores。缺少新模块的旧版本结算保留原顺序和结果。

`industry.generation/demand/used` 的校验上限来自已建设施及合法产出加成，代替旧固定100上限：公用电站可合法使容量超过100，但没有对应设施的999电仍被拒绝。过去一轮的记录可能跨过工人调岗/政策变更，因此按已建设施和最高合法政策/社会加成校验，不拿当前在岗人数否定刚完成的旧轮证据。烟尘仍限制0–100；used 不得超过当轮 generation 或 demand。独立 productionPower 仅记录旧机械坊实际付费通电批次×2，不能把化工、钢、玻璃、水务或除尘用电计入城市的机械生产证据。旧档缺字段保持缺省，下一真实结算前按0使用，不从总负载反推；有值时不得超过机械设施容量或当轮总used。

## 5 Home 与地方的共同接口

```js
CivilAdvanced.init(s)                         // 仅缺失时初始化，不赠物资
CivilAdvanced.buildings                      // ADR home buildDefs
CivilAdvanced.remoteFacilities               // 与Content.facilities相同配置
CivilAdvanced.gate(s,facilityId,nodeId='home')
CivilAdvanced.capacity(s,job,nodeId='home')
CivilAdvanced.workers(s,job,nodeId='home')
CivilAdvanced.generationCapacity(s,nodeId='home')
CivilAdvanced.demandCapacity(s,nodeId='home')
CivilAdvanced.demand(s,nodeId='home')
CivilAdvanced.prepare(s,{factor,run},nodeId='home')
// -> {generation,pollution}；矿物采集与独立公用发电
CivilAdvanced.run(s,{factor,run,powerAvailable},nodeId='home')
// -> {used,demand,pollution}；净化、化工、钢、玻璃
CivilAdvanced.refresh()/reset()/validate(s)
```

`run(job,count,cost,output)` 回调接收最终每人投入/产出：Advanced 已给 output 乘 factor，回调不再乘一次。回调实际扣除绑定仓库的材料、写 flow 并返回真正完成的批次数。地方调用同一 prepare/run，但回调绑定该地方仓，岗位容量读取 Municipal 已完成设施；不借用 home 发电，不写第二份地方仓库。made 技艺是共同知识，地方首次实际产出也可记录。

Services 的 run 同样消费传入的余电，不能重开独立发电或第二次生产循环。水务凭证、地方岗位分配和新公共服务项目的持久状态由其原模块承担。

## 6 存档与测试边界

新状态 `c.advanced={schema:1,made:{minerals:false,chemicals:false,steel:false,glass:false}}` 仅在字段缺失时创建。显式null/false、缺少或增加made键、非布尔标记、尚未研究却伪造的生产/工厂状态均拒绝。资源仍归既有home或地方库存；工厂与岗位仍归原设施/劳动力账。

当前 Advanced 11项与 Industry 12项专项回归通过，覆盖：

- 首城资格永久保留后即使人口下降仍可研究；上游实际产物驱动下一步。
- 旧档初始化无物资/标记赠品，局部损坏不当新档重发。
- 无电情况下用真实煤热配方生产四种材料，输出耗尽后仍保留技艺。
- 原料不足不产出、不透支；公用电站与旧电站燃料各付一次。
- 公共服务优先、净化/材料/机械争用同一余电，有限电量对应部分慢速工序。
- 合法160电记录可存，超过建成容量的伪造电力不可存。
- 付费矿煤扩建只增岗位，不重复计算同一工人。
- 克隆预测不改变真实库存或made；地方仓绑定不会写home库存，也不双乘factor。
- 从现有自然首城检查点的旧材料库存付费完成化工到钢/玻璃全链，停电后仍能产修复零件与材料。

上述最后一项是以真实检查点为起点的规则回归，不是已经操作过新版本浏览器的验收。材料技术通过不等于水务、千人城市、铁路或3000人城市群完成。

# 地球篇全流程与代际共同体

2026年11月1日用户补充：玩家延续的是社会与文明，不是一个永生人物。冰封者会老死，制度决定继承。发展依次覆盖收容所、村子、小镇、城市、城市群、国家与地球统一。此版以向星空出发为结尾，不展开星际战争与旅行。本文优先于早期交接中“太空篇继续扩展”的建议。

本文是完整地球篇的制作规格。当前工程已接入求生、村镇、代际治理和首条工业链，实玩证据见设计08，实际规则见设计09、11、12。后文城市、地区和终局不得仅凭规格存在就标作完成。

## 玩家身份与历史时间

玩家控制共同体的决策，不独占某具身体。第一代冰封者具备旧时代维护经验，后来的领导者来自聚落培养、地方精英、议事代表或继承家族。领袖死亡保留领土、技术、建筑、库存、法律、外交条约和社会矛盾；只移除个人能力与私人关系。下一任接手并留下自己的历史。

操作时间用模拟秒，1×按真实秒流逝；2×、4×统一加速。历史年自动累积，不使用“结束一天”。当前实现每600模拟秒记一历史年，人口成长、任期与寿命按历史年，生产和旅行按模拟秒。二者是叙事尺度与操作尺度，不宣称物理同一。此数值需完整地球篇实玩后校准；现有自然档已观察到跨年、孩子出生和领袖退休交接。

首位领导者苏醒时生理年龄28，冰封年限不计入生理年龄。年老从65岁出现健康提示，70岁后自然死亡风险逐年增加，85岁保证交接；医疗延长健康期但不能无限续命。突发事故不在没有预警与替代者时直接结束游戏。45岁前后引出培养接班人，建立学校/议事机构后可以更早准备。幼年人口不能因10秒岗位循环瞬间长大。

继承有至少两位可选候选人的恢复路径；若候选人全失，临时委员会从成年群体中产生，附带短期行政效率损失。继承失败的惩罚是政治真空、地方议价或短期抗争，不删除存档。能主动退休；这不是必须按的推进按钮。

## 各规模的可玩弧线

表中人口是正式版设计量级。当前村镇初版为验证完整经济闭环，先以20名本地居民加独立河谷触发“小镇”，木屋和长屋总容量最高48；这不是正式城市人口的替代。下一阶段需街坊住房、公共服务和持续迁入把人口真正扩展上去，并在完整实玩后重新校准早期称谓与门槛。到达规模必须同时满足生产、组织和地区条件，不能刷人口直接跳到国家。

| 阶段 | 人口与地理尺度 | 必须解决的矛盾 | 必需能力与故事 | 阶段完成证据 |

## 世界地理与地球统一的可实现规模

地球篇采用分层地点：开局本地探索点 → 邻近村镇与避难所 → 8个宏观区域。不是用八个村子假装统一地球；大区内部以城市网络、辖区人口和生产构成表达，重点地点可进入局部探索。

| 宏观区域 | 主导产业和灾变遗产 | 主要整合问题 |
| --- | --- | --- |
| 北陆寒原 | 燃料、重工业、冰封设施 | 能源分配、工业劳工和冬季交通 |
| 东陆河网 | 农业、人口、污染水系 | 粮食安全、洪泛治理、密集地方政体 |
| 西陆旧城 | 档案、机床、残余金融结算 | 城邦自治、工业标准与债务 |
| 赤道雨带 | 生物资源、变异生态、矿产 | 生态治理、变异群体公民权与道路建设 |
| 内陆荒漠 | 稀有材料、军用试验场、车队 | 水源、通行费和武装割据 |
| 南部高原 | 精密设施、旧观测站与隐蔽避难所 | 技术保密、教育交流和有限资源 |
| 大洋群岛 | 港口、船厂、海上航路 | 海权、燃料、独立岛屿联盟 |
| 极地遗产区 | 战前数据、轨道控制与能源节点 | 国际托管、军事化争议与灾害修复 |

没有孤立区域永久挡住唯一结局。必要遗产设施至少有技术替代路径：原物修复较快，工业重建较贵；外交封锁可经替代贸易或自主研发解除。

## 终局判定与叙事

地球统一须同时满足：8区已通过直接治理、联邦加盟、稳定附庸整合或共同体条约承认共同法；无仍在争夺主权的对等政体；各区供养达到底线；没有无法处理的重大分裂战争；共同财政可覆盖交通、卫生与行政；公民资格覆盖所有被纳入的人类群体。连续维持600模拟秒后成立。军事征服只是取得控制的一种方式，不自动满足整合。

玩家可以建立集中帝国、君主立宪国家、选举共和国、联邦、城邦联盟等不同共同体。不同制度有不同稳态成本与接纳方式；不可把某一种现实制度写成无代价最优答案，也不让被排除的居民在统计里消失。

首航前完成“发射场、可靠动力、生命保障、导航通信、全球授权/动员”五项。反重力坦克不是必须前置；军备路线与航天路线可分支。最后一个必要事件决定首次任务是勘测、通信还是迁居准备，改变结尾而不开启新地图。结局回顾首位与历代领导者、制度转变、族群待遇、科技恢复、战争代价和统一方式。

## 死锁与节奏限制

每一关键资源都至少有一条本地恢复路径；每一关键技术有保证发现或自主试制路径；唯一必需NPC不得被随机永久夺走。政治失败可通过改革、妥协、重组和培养继任者恢复。扩张前先建立能供养新增人口的系统，征服后不能立即凭空满产。

首次新增系统同时最多引出一个需要立即处理的新问题。已经掌握的重复劳动逐步交给岗位；新的决策是投资、供给、人才、协议和制度，不能只是增加需要每分钟点一次的按钮。首段时长按自然游玩实测，整篇时长在完整内容形成前不作保证。

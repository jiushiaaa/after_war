# 72 整体重规划：人口尺度、科技时代、飞升路线、政策与交互

> 2026-11-03。用户要求：不再开发，从头审视游戏，按世界顶级模拟策略游戏（群星、冰汽时代、城市天际线、文明、欧陆风云、维多利亚）的水准重新规划 UI 交互、玩法、科技树与政策，交给 Codex 实现。
>
> 本文是**设计方案**，不是已实现内容。它补充并在冲突处修订 `plan.md` 的 M3—M7 范围；`plan.md` 中的存档兼容、账本守恒、自然游玩与独立试验分开记录、不发布平台等约束全部继续有效。
>
> 世界观中的地火战争、冰封者、变异、灵能等均为本作改编设定，不标注为《这游戏也太真实了》原著已核实事实。

## 0. 审阅结论：现在差在哪里

| 问题 | 现状 | 玩家感受 | 根因 |
| --- | --- | --- | --- |
| 人口尺度太小 | 80 人成镇、400 人成市、千余人建国、八区统一 | 几百人就叫“国家”，不可信，也没有“治理亿万人”的分量 | 人口按逐人/逐队列模拟，岗位按个人分配，规模被性能和手操上限锁死 |
| 科技感弱 | 主线科技 26 项左右，止于炼钢、公用工程、风电、供暖，后期直接跳到航天 | 中后期没有“新时代来临”的惊喜，武器、建筑、生活方式几乎不变 | 科技树是“修复战前工业”的线性清单，没有时代、没有分支、没有改变社会形态的技术 |
| 变异与高科技未成体系 | 变异居民有身份/权利；机器人产业只是产线 | 设定里有变异，却没有基因、机械、智械、灵能的发展选择 | 缺少群星式“飞升路线”：科技 + 伦理 + 政治 + 身份的综合选择 |
| 管理方式不升级 | 城市以后仍在调岗位、点建筑、签协约 | 越往后越像会计，不像统治者 | 没有“人口群体 + 生产方式 + 法律”这种随规模抽象的模型 |
| UI 信息层级 | 原生 ADR 页签 + 长文本事件 + 局部看板 | 后期要在十几个页签和长弹窗里找原因 | 缺统一的告警栏、对象详情、地图图层和法律/科技总览 |

核心判断：**不能继续在“逐人模拟”上叠系统。** 需要像维多利亚 3 一样，把人口从“个人”升级为“人口群体（Pop）”，把岗位从“点人头”升级为“建筑的生产方式”，把制度从“几个事件选项”升级为“法律组”。这样人口可以到亿级，科技可以改变生产方式，政策可以改变人群利益，玩家的操作量反而下降。

## 1. 世界观补完

### 1.1 时间线（改编设定）

| 时期 | 事件 | 对游戏的意义 |
| --- | --- | --- |
| 战前 | 地球—火星双星文明，轨道工业、基因医疗、早期强 AI 已商用 | 地表遍布可回收的高科技遗产，但缺少维护体系 |
| 地火战争 | 轨道打击摧毁电网与城市带；火星方使用基因武器与自复制机群；地球方启用心智增幅实验部队 | 变异生物、失控机群、灵能残留三类遗留问题都有来源 |
| 大断裂（战后 0—150 年） | 全球人口从约 90 亿跌至约 4—6 亿，分散在避难所、旧城废墟、游牧带、工业城邦 | 解释“末日后人口仍以亿计”：不是人类只剩几百人，而是**彼此失联** |
| 冰封者苏醒 | 主角共同体从维修间起步 | 玩家并不是重新繁衍全人类，而是重新**连接、组织、整合**幸存人类 |

关键设定：**人口增长的主要来源是联络与整合，其次才是出生。** 远方有成千上万的避难所、城邦和流民带，它们本来就有人口。玩家通过探索、贸易、援助、加盟、战争把他们纳入共同体。这让“几十年从几百人到几千万人”在叙事上成立，也天然地把探索、外交、迁徙和治理绑在一起。

### 1.2 三类“后人类”遗产（飞升路线的叙事根）

1. **基因遗产**：火星基因武器造成的变异人与变异生物；同时战前也有成熟的基因医疗。变异既是创伤，也是钥匙。
2. **机械遗产**：自复制机群（失控）、战前工业机器人、义体医疗。高效、危险、需要电与零件。
3. **心智遗产**：心智增幅实验留下的“回响区”，部分变异人对其敏感。灵能路线从这里开始，**设定上保持神秘、低频、有代价**，不做魔法。

### 1.3 主题

“修复”不是回到战前，而是选择新的人类形态。终局问题从“能不能造火箭”扩展为：**我们以什么样的人类身份重返星空。**

## 2. 人口尺度重设计（最高优先级）

### 2.1 目标规模曲线

| 阶段 | 共同体人口 | 典型展示 | 统计方式 |
| --- | --- | --- | --- |
| 维修间/避难所 | 1—50 | 逐人 | 个人（现有） |
| 村落 | 50—800 | 逐人/户 | 年龄队列（现有 cohorts） |
| 小镇 | 1 千—1.5 万 | 千人 | **人口群体 Pop 启用** |
| 城市 | 5 万—50 万 | 万人 | Pop |
| 城市群 | 100 万—800 万 | 百万 | Pop，按地区聚合 |
| 国家 | 1000 万—1.5 亿 | 千万 | Pop，按省聚合 |
| 统一地球 | 4 亿—20 亿（随时代恢复） | 亿 | Pop，按大区聚合 |

时间支撑：游戏内跨度约 200—400 年（现 `YEAR=600` 秒，一局 8—15 小时实时可覆盖）。人口来源比例目标：前期出生 30% / 接纳 70%；中后期接纳与整合仍占一半以上。

### 2.2 两层人口模型

**第一层（现有，保留）**：村落以前的逐人/队列模拟，保留冰汽时代式的生存紧张感。

**第二层（新增）Pop**：小镇登记时一次性转换（有叙事事件“第一次人口普查”）。

```text
Pop = { 地区, 阶层(劳工/技工/农户/知识/管理/资本或合作社), 文化, 身份(人类/变异/改造/义体/智械), 规模(整数人), 就业建筑, 生活水平, 识字率, 激进/忠诚 }
```

- 建筑不再“点 N 个人”，而是提供**岗位数**（例：灌溉农场 1 级 = 5000 农户岗位）；Pop 自动按工资/生活水平流动就业（维多利亚式），玩家只设优先级和法律。
- 消耗按人均需求篮子（粮、衣、燃料、医疗、教育、电、信息……），随时代升级；缺口降低生活水平 → 激进 → 政治压力。
- 出生/死亡/迁移按 Pop 规模的速率结算；保留整数和守恒（每次结算记录“出生 +x、死亡 −y、迁入 +z、迁出 −w”）。
- 性能：Pop 数量按“地区 × 阶层 × 身份 × 文化”组合，一般在 50—400 个之间，与总人口无关；8 区统一地球也不会爆炸。

### 2.3 规模化后要同步调整的东西

| 系统 | 调整 |
| --- | --- |
| 资源 | 引入**量纲**：村落以“份”，城市以“吨/千吨”，国家以“万吨”。UI 自动换单位；账本仍存基础单位（浮点/大整数安全范围内，必要时以“千”为基础单位存档） |
| 建筑 | 从“一座陷阱”升级为“等级 N 的工业区/农业区/住宅区”（天际线式分区 + 维多利亚式建筑等级） |
| 阶段门槛 | 镇：1 千人 + 镇议会；市：5 万人 + 市政服务覆盖 80%；城市群：3 座 10 万+ 城市 + 物流网；国家：1000 万 + 宪制；统一：全球 70% 人口在共同法下 |
| 战争 | 兵员来自 Pop 动员比例（1%—10%），伤亡按人口计 |
| 叙事 | 保留“职业代表”与少量可记住的人物；Pop 是群体不是角色 |

### 2.4 旧档兼容

- 新规则以 `populationRule: 2` 标记，只用于新档。
- 131/138 等旧档：**不改写历史人口**。提供可选、只读的“统计口径说明”，或在旧档上走一次显式、可记录的“普查迁移”事件（把现有人口按 1:1 转成 Pop，不凭空加人）。不允许静默放大旧档人口。

## 3. 科技体系重设计

### 3.1 结构：七个时代 × 六条路线 + 飞升

参考文明（时代）+ 群星（卡牌抽取/方向选择）+ 维多利亚（科技解锁生产方式而非直接加成）。

六条常驻路线（与 plan.md §8 对齐并扩展）：**农业生态、材料制造、能源、医学生物、信息与控制、社会组织**，外加**军事**作为横切。

| 时代 | 大致人口 | 代表科技（每条路线举例） | 代表建筑/生产方式 | 代表武器 |
| --- | --- | --- | --- | --- |
| Ⅰ 拾荒（0） | <800 | 净水、金属回收、土壤辨识、草药 | 陷阱、粮棚、手工坊 | 弓弩、矛、自制火药枪 |
| Ⅱ 复兴手工业 | 千—万 | 灌溉、冶铁、蒸汽机、印刷、基础卫生 | 水车磨坊、高炉、蒸汽工坊、学堂 | 栓动步枪、火炮、骑兵/机动车 |
| Ⅲ 工业重建 | 万—百万 | 电网、炼钢、化肥、内燃机、无线电、疫苗 | 火电厂、钢铁联合体、化肥厂、铁路 | 自动步枪、机枪、卡车化步兵、早期装甲 |
| Ⅳ 现代 | 百万—千万 | 半导体、核裂变、抗生素量产、高速铁路、计算机网络 | 核电站、芯片厂、医院网络、集装箱港口 | 坦克、直升机、导弹、无人机 |
| Ⅴ 信息与自动化 | 千万—亿 | 机器人工厂、基因测序、卫星网、聚变实验堆、量子计算 | 自动化工厂、垂直农场、数据中心、轨道发射场 | 无人机群、动力外骨骼、精确打击 |
| Ⅵ 先进（战前水平回归） | 亿级 | 聚变电站、纳米制造、合成生物、强 AI、轨道工业 | 聚变堆、纳米工厂、生物反应器、太空电梯原型 | 电磁炮、激光防空、自主作战平台 |
| Ⅶ 飞升 | 统一地球 | 见 §4 四条飞升路线 | 各路线专属奇观 | 各路线专属 |

**关键规则：**

1. **科技解锁生产方式**，例如“高炉 → 转炉 → 电弧炉”是同一钢铁厂的三种生产方式，切换要付改造成本、改变投入与雇佣阶层。这让科技真正改变经济，而不是 +5%。
2. **回收遗物可跳级**：探索中找到的战前设备可以提前“理解”某项科技（降低成本/提供研究方向），但不能直接量产（plan.md §6.3“发现≠掌握”）。
3. **研究点来源**：知识产出（学校、大学、研究所、数据中心）+ 遗址研究 + 外交交流。研究速度随识字率和知识阶层 Pop 增长。
4. **时代转换是大事件**：每进入新时代，触发冰汽时代式“时代议会”：选择本时代的社会方向（法律组提案），并解锁一组新视图（如Ⅲ时代解锁电网图层，Ⅴ时代解锁信息网图层）。
5. **科技数量预算**：每时代 20—30 项，共约 180 项；每项必须至少解锁一个生产方式、建筑、法律、单位或决议之一，禁止空加成项。

### 3.2 科技树 UI

- **时代横轴 × 路线纵轴**的网格总览（文字节点 + 连线，ADR 风格黑白），当前时代展开，过去时代折叠，未来时代只显示“?”。
- 每节点：成本、时长、前置、**“解锁后你能做什么”**（直接链接到建筑/法律/单位，沿用本轮已做的“去建”跳转）。
- 群星式“研究方向卡”：每条路线同时只提供 3 张候选，抽卡受当前遗址、法律、人口阶层影响，制造分化与重玩性。

## 4. 飞升路线（中后期核心选择，类似群星飞升 + 冰汽时代信仰/秩序）

进入Ⅴ时代后可选择**主飞升**一条，**辅修**至多一条（代价递增）。每条路线同时包含：科技分支、法律要求、Pop 身份变化、社会利益冲突、专属建筑/单位、专属结局叙事。

### 4.1 基因飞升（生物科技）

- 起点：变异研究、基因测序、变异人医疗。与“谁属于共同体”主线直接相连。
- 科技：基因疗法 → 定向改造（耐寒、抗辐射、肺适应）→ 生态工程（改造变异生物为家畜/工兵）→ 新人类亚种。
- 玩法：可将 Pop 身份改为“改造人”，降低特定环境的生存成本、提升特定岗位效率；需要“生命伦理法”。
- 冲突：纯人类主义派 vs 改造派；变异人可能被视为“先行者”或“实验品”，由法律决定。
- 失败代价：基因事故、生态失控事件。

### 4.2 机械飞升（义体与赛博）

- 起点：战前义体医疗、外骨骼、机器人工厂。
- 科技：神经接口 → 全身义体 → 意识备份 → 机械化公民。
- 玩法：义体 Pop 不需食物但需要电与维护零件；劳动效率高，寿命长；能源/零件断供即是人口危机。
- 冲突：义体垄断（谁买得起）→ 阶层分化；与资本/合作社法律强绑定。

### 4.3 智械路线（强 AI 与合成人）

- 起点：回收战前 AI 核心、自动化工厂、失控机群的“驯化”。
- 科技：受限 AI → 管理型 AI（行政效率）→ 合成人劳动力 → AI 公民权或 AI 治理。
- 玩法：可用 AI 管理地区（大幅降低管理负担，正好解决后期手操问题）；合成人作为 Pop 身份。
- 关键法律：**智械权利**（工具 / 受监护者 / 公民）。选“工具”有起义风险；选“公民”需要重议共同法。
- 威胁：战争遗留的自复制机群作为中后期“危机势力”（群星天灾式），可以被摧毁、隔离或谈判。

### 4.4 灵能路线（心智与回响）

- 起点：探索“回响区”、部分变异人的敏感者。设定保持低魔：感知、心理影响、共感通讯为主，不做火球。
- 科技：回响观测 → 共感训练 → 灵能通讯网（无电力远距通讯）→ 集体意识实验。
- 玩法：灵能者为稀有 Pop（万分之一级），提供情报、外交、稳定度、远距协调；过度使用造成“回响污染”和精神事件。
- 冲突：宗教化、精英化或公共化；与文化/宗教系统合并（plan.md §10.5）。
- 终局：可选择“心智网络”式共同体（偏群星灵能飞升，但必须保留个体与代价的叙事）。

### 4.5 不飞升：生态复原路线

- 专注修复地球：去污染、恢复生物多样性、可持续能源。
- 优势：稳定、低风险、人口与幸福最高；首航目标偏向“带着地球生命出发”。
- 设计要求：它必须是一条完整、有竞争力的路线，而不是“什么都不选”。

### 4.6 结局矩阵

首航结局由**飞升路线 × 统一方式（协商/中央）× 共同法中身份条款**组合，生成不同的文明回顾与出发宣言。约 5 × 2 × 3 = 30 种组合，用模板 + 关键事件回放生成，不需要 30 段独立剧本。

## 5. 政策与制度：法律组（维多利亚式）+ 法典（冰汽时代式）

### 5.1 两层

1. **前期“法典”（冰汽时代）**：村落—小镇阶段，单次签署、带冷却的具体法令（配给、童工、急救、守夜、墓葬、学徒）。每条立即改变规则，并有社会反应。现有“同一口锅”“方针议定”扩展为约 20 条。
2. **中后期“法律组”（维多利亚）**：每组一个当前值，改法需要政治支持与过程（提案 → 辩论 → 通过/失败），期间有利益集团反应。

### 5.2 法律组清单（初版）

| 法律组 | 选项示例 |
| --- | --- |
| 政体 | 议事会、代议共和、技术官僚、委员会、个人统治、AI 辅政（智械路线） |
| 经济体制 | 公共计划、合作社经济、混合经济、自由市场 |
| 劳动 | 无保护、基本保障、工会、合作所有制 |
| 公民资格 | 分层、居住、平等（现有，扩展到改造人/义体/智械/灵能者） |
| 生命伦理 | 禁止改造、医疗限定、自愿改造、强制优化 |
| 机器权利 | 工具、受监护者、公民 |
| 心智与信仰 | 世俗、宽容、国教化、灵能公共化 |
| 中央地方 | 集权、分权、联邦（现有扩展） |
| 军事 | 民兵、职业军、义务兵、自动化军 |
| 环境 | 开发优先、平衡、保护优先 |
| 信息 | 管制、开放、全联网 |

### 5.3 利益集团（6—8 个，聚合 Pop）

工匠与工人、农户、知识界、管理/技术官僚、资本或合作社、变异人社群、改造派（飞升后出现）、宗教/回响团体。每集团有支持度和诉求，诉求与法律、生活水平、飞升路线挂钩。**政治就是让足够多的集团接受你的改法。**

## 6. 经济、建筑与城市

- **分区 + 建筑等级（天际线）**：城市内用住宅/工业/农业/服务/科研分区，建筑按等级扩建；地图上有地块和交通。
- **生产方式（维多利亚）**：每类建筑 2—5 种生产方式，由科技解锁、由法律限制（如“合作所有制”下资本型生产方式不可用）。
- **市场与物流**：地区市场有价格；短缺推高价格；物流网络决定市场是否连通（现有在途/运力账本复用）。
- **能源层（冰汽时代 + 天际线）**：供暖/电力/信息三张网，覆盖范围显示在地图图层上；断网是城市危机的主要来源。
- **预算**：税收（依法律）、公共服务支出、建设、军费、科研；赤字有债务（现有清算/信用复用）。

## 7. 军事与外交（从文明/欧陆借鉴，有限）

- **军队是编组不是单位格**：师/集团按时代装备（步枪→机枪→坦克→无人机群→电磁炮/自主平台），属性=装备 × 训练 × 补给 × 士气。
- **战线（维多利亚 3/HOI 简化）**：两国接壤处形成战线，玩家分配编组与目标，结算按补给和战力。现有宏观战线可复用。
- **外交**：好感、条约、联盟、通行、贸易协定、附庸/加盟、战争目标（欧陆式宣称与和谈分数）。现有自主外交、联盟、背约、调停全部复用，但入口收拢到“国家详情”。
- **危机势力（群星）**：失控机群、基因生态灾变、回响风暴，作为中后期全球威胁，推动合作与统一。

## 8. UI 交互重设计（保持 ADR 文字风格，不换引擎）

原则：**文字仍是主体，但后期用“桌面”组织信息**。早期保持原版 ADR 极简；每次规模升级解锁一张“桌”。

| 解锁时机 | 新增视图 | 参考 |
| --- | --- | --- |

| 城市 | **分区地图**（ASCII 网格，图层：供暖/电力/污染/服务覆盖）、**法律页** | 天际线信息视图 |
| 城市群 | **地区地图**（现节点图升级为有地形的省份图）、**市场页**（商品价格/供需） | 维多利亚市场 |
| 国家 | **国家概况**（大纲 outliner：省/军/条约/建筑队列）、**外交页**、**利益集团页** | 欧陆/维多利亚大纲 |
| Ⅴ时代 | **飞升页**、**全球图**（大区、危机势力） | 群星 |

通用交互规范：

1. **每个数字都可追溯**：悬停/点击显示“由什么组成”（tooltips 树，维多利亚式）。
2. **对象详情面板**：点任何地点/Pop/建筑/国家，打开同一格式详情（状态 → 问题 → 可做 → 明细）。
3. **时间控制**：暂停/1—5 档速度，快捷键空格与数字键（已实现可恢复暂停，扩展档位命名）。
4. **通知分级**：短消息进左侧日志；重大事件弹窗并自动暂停（可设置）；常规事务进月度摘要。
5. **窄屏**：沿用本轮单面板纵向布局；大地图提供平移和地点列表等价视图。
6. **不使用新前端框架**：继续 jQuery + 原生 DOM + CSS；地图用等宽字符网格或少量 SVG（现有地区图已用）。

## 11. 风险与需要用户决定的事项

1. **人口迁移口径**：旧档是否提供“普查迁移”（1:1，不加人）还是完全保持旧规则？建议：旧档保持旧规则，仅新档用 Pop。
2. **灵能的分寸**：建议低魔、有代价、可选；若用户希望更“科幻魔法”，需另定。
3. **飞升是否必选**：建议非必选，生态复原为完整第五路线。
4. **实时长度**：亿级人口与七时代会拉长游戏；建议默认 12—15 小时，提供“快节奏”开局选项（更早联络、更高接纳率），不靠单纯加速。
5. **性能**：Pop 模型下长期账本增长需按 plan.md §14.4 做摘要/分页；务必先测再优化。

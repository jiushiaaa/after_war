# 经济社会政治与领土整合

这些系统服务同一成长曲线：先解决眼前生存，再把个人劳动转成交接得下去的社会组织。当前首段只运行人口、岗位、口粮、信任与配给；全文其余内容是后续实现规格，不能当成现有功能。

## 居民和避难所经营

参考《辐射避难所》的居民适岗、训练、装备、设施供养与外出探索思路，采用其[官方介绍](https://fallout.bethesda.net/en/games/fallout-shelter)能支持的机制方向。界面仍为ADR按钮与职业列表，不移植横剖面建筑、不增加每日奖励或手动收取所有生产物的负担。

人口分成人劳动者、受教育者、儿童、老人和暂时伤病者。早期以少数职业人物展示，中后期以职业/地区/年龄群体统计，重要代表保留身份、经历与关系。不是每个居民都要逐人点装备。训练占用时间、食物和教师岗位；经验来自实际工作，不能无限点按钮刷技能。

人才能力采用建设、生产、研究、医疗、交涉、指挥六项，熟练度有上限。适岗提高效率，受教育提高转岗能力。外骨骼、工具和机器人提高某些任务能力，但产生能源和维护需求。高级人才死亡会失去个人经验，学校和技术档案保留共同知识。

幸福/满意度拆成可追溯需求：食物、水、住房、安全、医疗、政治地位。UI只在相关需求出现后显示其中重要项，库存提示给流量，事件给冲突；不提前摆六根仪表盘。长期匮乏引出罢工、迁出或自治诉求。短缺可恢复，不一秒钟连锁全灭。

## 经济结算

本地生产每10模拟秒按同一事务结算：校验岗位与容量 → 检查投入 → 生产 → 居民消费 → 设施维护 → 更新短缺与库存。运输到货独立按旅途时间入账；物资发出即离开起点，不能两处同时计入。电力以发电能力减负载计算，储能作为有限缓冲，不做无限电力库存。

地区经济包括公共仓、家庭消费和企业/作坊账本。初期共享仓，无货币；市场在剩余产品交换出现后解锁，再出现结算凭证。货币内部转移守恒：政府采购进入居民/企业收入，税收从对应余额扣除。外贸余额、贷款发行和核销单独记账，不把货币当伐木掉落物。

价格根据供需缺口、库存覆盖时间、运输成本与制度限制缓慢变化，有上下限和调整速度；不因一次买卖瞬间涨到无限。限价可以缓解购买压力，但低于成本会造成供给退出；配给保证最低需求但需要行政和库存；自由交易有调节能力也有不平等。债务有利息、期限与信用，破产触发重组、资产转让、财政紧缩或外部担保，不直接清空城市。

| 时期 | 新经济问题 | 玩家实际操作 |
| --- | --- | --- |
| 收容所 | 如何分口粮 | 一次必要事件，之后可改议 |
| 村镇 | 专业岗位吃掉共同储备 | 调整岗位、农田与公共粮库 |
| 小镇 | 工资、价格、私人和公共生产 | 市场规则、公共采购、劳动条件 |
| 城市 | 税收、服务、污染、贫困 | 分别解锁税制、卫生、教育和保障政策 |
| 国家 | 地方财政、贸易与军费 | 配额/补助/共同税，维护跨地区基础设施 |
| 全球 | 产业互补与区域不平等 | 均衡投资、统一结算、跨区公共服务 |

## 政治体系是四个可组合维度

城邦、联邦、帝国描述共同体结构；君主、选举描述权力来源；宪法与行政集权描述权力边界。不能放在一个互斥下拉框里混为同一概念。

| 维度 | 选项 | 代价与作用 |
| --- | --- | --- |
| 共同体结构 | 单一城邦、城邦联盟、单一国家、联邦、帝国附属体系 | 联盟成员自主但动员慢；联邦整合较稳但有议价；单一国家协调快但行政压力大；帝国附属收入不完整且有反抗风险 |
| 领导产生 | 推举、定期选举、指定继任、世袭 | 选举需要教育/组织且有政策周期；指定快但合法性依赖成绩；世袭交接预期明确但能力不确定；推举适合小规模 |
| 权力约束 | 个人裁决、议事限制、成文宪法、独立审查 | 约束增加协商成本、减少滥权冲击；个人裁决快但继承风险集中 |
| 中央地方关系 | 集中委任、协商自治、宪定分权 | 集中提高可征调率且占行政；自治降低地方抗拒但限制征税/征兵；分权需要稳定制度与争端程序 |

组合示例：城邦联盟＋选举代表＋盟约＋自治；单一国家＋世袭＋成文宪法＋集中委任（君主立宪）；联邦＋选举＋成文宪法＋宪定分权；帝国附属＋世袭＋个人裁决＋协商自治。高自由组合不是所有加成都可相加：例如地方自治意味着中央不能随意抽取全部税收。

建国不是按人口自动更名。在第一次跨地区共同议事/兼并压力后提出制宪事件，选择结构和权力来源，再由后续现实冲突引出约束与地方关系。改革需要动议、支持、资源和过渡时间，有冷却及既有利益反应；不得每10秒换政体刷收益。

## 政策目录与依赖

| 领域 | 首次触发 | 选项与影响 |
| --- | --- | --- |
| 配给 | 首批居民与共用库存 | 均分、紧缩、厚给；消耗、产出和信任 |
| 工时 | 工坊/专业劳动、首次工伤或交付压力 | 正常、加班、轮休；产出、伤病、长期满意度 |
| 接纳 | 有人请求收留且床位紧张 | 开放、容量登记、严格审查；迁入速度、行政成本、被排斥者关系 |
| 安全 | 兽袭或武装来访 | 民兵轮值、专业守备、协防条约；岗位、军费、外交依赖 |
| 公共卫生 | 首次疾病/诊所 | 基础救治、全民服务、分担费用；财政、劳动力健康和贫困 |
| 教育 | 学徒和记录系统 | 师徒、公共学校、精英学院；人才数量、流动性、阶层差异 |
| 所有权 | 市场/规模作坊 | 公共经营、合作社、私人经营、混合经营；投资效率与分配 |
| 税收 | 稳定市场和公共服务 | 实物定额、交易税、所得税、地租；不同税基与行政能力 |
| 保障 | 老人、伤病、自动化失业 | 家庭互助、公共最低保障、职业保险；消费、财政和社会稳定 |
| 公民资格 | 变异群体/新征服人口要求参与 | 分层资格、居住资格、平等公民；人才迁入、地方合法性、既得利益反应 |
| 技术治理 | 机器人、遗传医学、旧武器 | 审慎许可、公共开放、军用优先；研发、风险、信任与外交 |
| 信息制度 | 广播、网络、冲突消息 | 公共通报、商业传播、严格控制；透明度、动员和错误积累 |
| 环境 | 污染累积/农地减产 | 排污容忍、收费、硬性标准、公共修复；工业成本、疾病、土地恢复 |
| 兵役 | 区域战争 | 志愿、征募、轮役；军费、民心、生产损失 |
| 战后治理 | 首次控制有居民地点 | 军事管制、恢复自治、共同法整合；短期控制与长期合作 |
| 继承 | 领袖年龄/首次任期结束 | 按现行政体执行，紧急临时委员会保底；培养、合法性和稳定 |

政策后果必须作用于经济或政治规则，不能只扣“善恶点”。短期收益与长期代价在选择前说明方向，首次触发给少量可比较选项；已解锁后通过原生事件窗口查看和修改。

## 派系与合法性

派系从实际人口利益生成：农户、工人、商人、技术人员、守备集团、地方自治派、变异居民代表。人口未形成相关职业时不出现。支持度由政策、生活状况、政治参与和战争经历计算，权重由人口、组织和资源决定。

合法性由程序承认、供养绩效、权利兑现和承诺履行构成；压制可以暂缓抗争但累积风险，不消除诉求。反对派并不自动是敌人，可以通过代表席位、补偿、改革和地方公约处理。战争胜利增加威望，也会增加军人集团影响。领袖更替检验程序，个人威望不100%继承。

## 领土外交与战争

每个地点至少记录：人口/生产、所有者、关系、自治、整合度、反抗、道路连通、供给、守备、地方承诺。探索发现地点后才出现它的交互。没有地图全部点亮和各派系百科开局列满。

接触 → 交换信息 → 通行/贸易 → 协防/担保 → 联盟/附庸/加盟 → 整合是可渐进的外交链，具体接受度由利益、信任、力量、文化距离与承诺履行构成。军事征服形成“控制”，供养与治理形成“整合”，两者独立。

| 手段 | 能获得什么 | 持续成本与失败方式 |
| --- | --- | --- |
| 开垦/修复无人点 | 自建生产和设施 | 建设、运输、环境风险 |
| 救助换合作 | 信息、信任、渐进联系 | 实际供给承诺，失约影响声誉 |
| 联盟/联邦加盟 | 共同交通与政策范围内的税/兵 | 地方权利、共同支出、代表协商 |
| 附庸/保护国 | 有限贡赋与通行 | 防卫义务、有限内政、独立诉求 |
| 征服 | 地点控制和停战条件 | 战损、占领、重建、仇恨、反对联盟 |
| 谈判统一 | 正式共同法与全球承认 | 保障、利益调整、制度可接受性 |

战争以行动、补给和阶段事件呈现，不做即时战棋。部队由实际居民、装备、训练和组织组成。兵员离开生产岗位，装备损耗和伤病回流，前线补给不足就暂停推进或撤退。反重力坦克强但维护贵，不能自动吞并一切；轻兵、道路、情报和盟友仍有作用。

## 变异社会与生物

变异居民有正常的职业、文化、家庭和权利；生理差异只影响具体生态适应和医疗需求，不决定善恶。初期通过观察足迹、救助伤者和贸易接触逐步出现。野生生物分迁徙、捕食、巢群、可驯化类型；对抗、围护、绕行、生态修复各有成本。

战争污染区并非人人必死或必有宝物。探索需要防护/药品/清水，风险事先可见；损失有上限并有撤退选项。高科技遗物作为少量具体发现出现：有电池但关节损坏的外骨骼、残存识别逻辑的机器人、缺少场发生器的反重力坦克。修复它们是一条产业任务，而非拿到就无限使用的奖励。

## ADR界面约束

顶栏只放地点：维修间/聚落中心、村外/地区、旧公路/远方。地点可随规模更名，不把“人口、经济、政治、外交、科技”直接变成开局五个页面。资源在右侧，收入与维护在悬浮提示，职业用原作增减箭头。建筑、研究、外交行动使用原作按钮，较长解释在必要事件窗，决定结果写入左侧。

当同地点可见操作超过两列时，按照原作地点和设施解锁分区，已完成的一次性研究不永久占据主行动列。政策首次由NPC提出，之后才有对应制度入口。右下角只保留存档和已解锁倍率。没有空音乐/语言控件、说明页、章节门和按天推进。

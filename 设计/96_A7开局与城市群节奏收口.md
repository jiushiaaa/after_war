# A7 开局与城市群节奏收口

2026-11-06；接续设计94及A7双路线证据，不新增国家系统。

## 判断

上一轮的长空窗混有十年稳定性停留、排错与自动玩家反复导航，不能直接作为正常主线时长。实际缺口：开局每次人口变化要重配工；万人城后下一步引导消失；三个城市议题同一时刻触发；两城协作与第三城的运力选择埋在折叠页。不能靠加长计时器或把默认确认算作抉择修补。

## 本轮范围

1. 新档增加 `pacingVersion:1`。开局工坊与8人出现后，开放有边界的轮值分工：供养储备／修造优先。协调员占一名现有成人；每60秒实付木料2、食物1，按现有岗位、产量和容量安排工作，无收益倍率。缺维护暂停，手动调岗撤销授权；城市公署成立后旧委托结束，由现有机构接续。只管理六项基础民用岗位，不动守备、司机和在途者。
2. 议题跟随实际问题出现。城市生产先议，临床工序在具备受训医护后议，接班培训在真实缺口出现后议。两城协作与三城运力各有实际规则选择，仍由原系统付款、发货、调度。保留既有菜单自主先行，不以事件锁死行动；已自行办理的事项不重复弹窗。
3. 城市—城市群继续显示下一步，读原规则的阻塞原因，给出直达入口；施工与运输显示进行中及预计余时。城市日常交接、培训、预算与机构委托集中在已有入口，默认折叠，不另建看板体系。
4. 核验用正常推进脚本与稳定性脚本分开。统计实付策略变化、必要操作与最长无事可做段；导出、截图、排错、故意断供单列。不以这轮局部验证冒充两条12—15小时真人全流程。

自然运行补充：原镇达到人数门槛后，持续新批次接纳仍会支出工具，与公共服务交接竞争。引导只揭示这一真实支出并指向原有暂停入口，不替玩家取消旅队；已出发家庭继续履约。轮值也必须尊重明确的“教师下田”决定，暂停委托而不能在下轮撤销调岗。

# 五城用工、通勤与粮酬

2026-11-04。按74继续A3，从原生233接续。仍只处理已有五城，不增加国家菜单。

## 1. 这一轮解决什么

原来的跨城招工是120人的家庭迁居：必须搬家，再由接续工坊培训。它不能表达“保留住所，去另一城工作”。各城机动劳力、家庭食物和就业城市的公共负担，也没有通过工资发生联系。

新增的是有限的公共劳务委托，不是全社会就业市场。各城安装120个工位，接替一部分原有生产或教学排班。用工可以来自本城，也可以来自其他已通路的真实城市。签约后机构逐班复核并办理，玩家不需要每十秒点一次。

## 2. 人口与岗位

- 居民户籍及出生死亡仍在原城的人口底账。通勤名册只是这些居民的职责标记，绝不再次加入人口总数或移民账户。
- 每班24、60或120人，从18—50岁的现有居民中选出；不占专业资格、正在学习、既有安置或另一班的同一批人。最长通路720秒，往返加驻班最长1740秒，出发年龄不会在途中触及退休或80岁死亡线。
- 来源先留足现有生产与服务岗位，再调动机动劳力。轮班人员明确占用`wageworker`，不能同时被来源城其他岗位、迁居、专业课程选走。
- 到岗时，雇用城市减少对应的普通排班，再由实际劳务生产接续；外来人员不算当地新增劳力。课堂助教实际覆盖儿童，不能只生成知识。
- “机动劳力”不是失业率。现阶段没有足够的家庭资产、求职意愿与劳动市场模型，不能把没排公共岗位的所有成年人叫失业人口。

## 3. 五城差异与真实需求

| 城市 | 劳务工位 | 每人每轮投入 | 能力 |
|---|---|---|---|
| 炉火城出发片区 | 木作供应 | 工具0.01 | 木2 |
| 湖滨 | 粮作供应 | 工具0.01 | 粮2.8 |
| 矿岭 | 回收供应 | 工具0.01 | 废料1.6 |
| 河口 | 药务供应 | 粮0.2、废料0.1、工具0.01、知识0.02 | 药0.3 |
| 桥原 | 学堂助教 | 木0.1 | 知识至多0.3，同时承担20名儿童课堂 |

若儿童或接班课程超过旧学堂容量，已安装的工位优先调作补充课堂，最多120处；对应减少劳务空缺。额外教师来自本地真实劳力，继续消耗木料和口粮。现有超出可用空间的班次结清返乡，不把教师上限无限调高。暂停劳务不撤销儿童课堂。

每城先付木120、工具24、知识12，20名真实本地居民安装120秒。工位不是随着人口自动增长的免费岗位。

物资岗位按实际库存缺口决定是否发班，课堂按真实儿童人数决定需求。已到岗班次的供应份额从普通生产中预留，避免普通生产抢先补满仓库、让已招居民无活可做。工位上限不等于当前缺工，库满时机构保留未来委托并停止发班，不空转工资。每班至多30轮，只有实际劳动才挣粮酬。库存足额的物资不继续囤积；实际只需要部分人工作时按实际人数支付，其余预付退还。教学在知识足额时仍需维持课堂，停止增加知识库存。岗位办事与本地基本服务争用有限劳力和预算。

本地用工不占车、不额外占床，路费为零。跨城用工能把外城劳力、工资与本城公共服务联系起来，但需要更多公共承担。不能把远途通勤设计为无条件优于本地培养。

## 4. 临住与运输

- 保留来源家庭住所。雇用城市另从真实空床中预留班组临住床，出生、迁居不能占用。
- 持续用工约保留临住床，而非每次返乡即释放。否则本地出生在暂停期间填满住房，导致恢复用工后永远无法重开。
- 每人的临住整备实付木1、工具1/6、药0.1；每60秒维护木0.02、工具0.002、药0.005，计入雇用城共同事务额度。暂停劳务并不自动解除房屋责任；取消未来用工后，仍为已经出发且尚未离开工作地的班次维护。
- 连续未续办临住维护会停止后续发班/驻班工作；已保留床位不因账上缺料突然消失，也不驱逐原住民。
- 使用来源公用站现有的一组勤务车、4名成年驾驶员。从出发、驻班到返乡一直占车，与共同供料、迁居竞争。已有迁居约优先，不能重复承诺车辆。
- 全程使用签约出发时的真实公路路径。来源预封存全程、全班及4名驾驶员口粮；开班不直接改写人口或时间。

当前车辆随班驻留，是分期轮班通勤，不是假定每日往返。其长途效率差是实际取舍；公交班车、多个车组与日常往返留到下一段设计。

## 5. 工资、公仓与家庭守恒

货币与私人金融尚未闭环，本轮使用实物粮酬。

1. 雇用城市从本地公仓封存每人每轮粮0.24、最多30轮的工资。此时是公仓发出、工资托管，未算家庭收入。
2. 实际工作才将相应工资转给班组；原料消耗、产品产出分别计入雇用城市账。
3. 通勤居民在家不再领取公共口粮，全程吃来源预封的旅粮。每轮驻班由雇用城市实付粮0.12/人作为口粮返还，随车运回来源公仓。诊疗与水务按照实际驻班人数增加，不占两城的同一份口粮。
4. 提前结束时，未挣工资退回雇用公仓，本期授权额度不重置；已挣工资保留，不能靠取消委托收回。
5. 返乡后：剩余旅粮和驻班返还进来源公仓，工资进入来源家庭食物账户。当地结算先消费这些已有家庭食物，再取公共口粮；未用余额保留。工资不是新的生产。

本地班次没有旅粮、食宿返还和运输，结班时同样把已挣工资记入家庭食物账户。

必须成立：

```
世界人口 = 初始世界人口 + 出生 - 死亡
城市居民 = 既有名册 + 出生 - 死亡 + 真实迁居净额
工资封存 = 已挣工资 + 未挣托管（或已退回）
旅粮封存 = 已食用 + 剩余旅粮（或已随车退回）
家庭累计收入 = 家庭食物余额 + 已食用
公仓 = 原有 + 真实生产 + 收入仓库 - 真实消耗 - 发出仓库
```

家庭食物是按城市汇总的居民账户，不冒充逐户财富、货币工资、私人银行或完整消费市场。公共支出折值仅用于现有授权额度，不能兑换出物资。

## 7. 兼容、验证与下一步

`cityLabor.schema=1`只由实付安装显式启用；233及更早原档不自动增设工位、人口或家庭账户。旧费率与历史导出不改写。新费率未来变更必须版本化。

规则验证覆盖五城实际投入、去程/驻班/返程、重复用工、公共车辆竞争、住房预留、暂停恢复、工资退还、私人食物、原生导出导入和二十年运行。自然证据独立从233经正常UI推进；具体结果见本轮验收，不能把规则副本当作自然二十年。

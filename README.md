# 战后文明

基于 A Dark Room 官方源码的科幻废土文游。保留原生页面、文字、按钮、冷却、库存和随机事件，随真实发展逐步解锁。玩家延续一个共同体，领袖会衰老、死亡和继任。

地球篇主线：求生 → 聚落 → 村镇 → 城市 → 城市群 → 建国 → 统一地球 → 向星空出发。本版不做星际战争和旅行。

## 当前接力

**城市群 → 建国的可玩主线已自然验收，继续推进国家阶段。** 经济政治、战争外交按阶段接入；只有阻断主线、存档、资源守恒或主要交互的问题才优先回头修，避免长期停留在前期细节。

先读 [AGENTS.md](AGENTS.md) 和 [HANDOFF.md](HANDOFF.md)。更细的实现与历史见 [当前开发接力](设计/10_当前开发接力.md)、[完整地球篇进度评估](设计/42_完整地球篇开发进度评估.md)。`HANDOFF.md` 是跨电脑交接的首要入口；历史记录中的暂停状态、Mac 绝对路径、浏览器变量和临时日志不是新电脑的当前状态。

当前地球篇通关原型已通过自然游玩验证：从118原档完成剩余五区、地球共同法、航天制造与生命保障、无人先遣首航，最新通关后的接续档为126。国家阶段已有八区协约、经济制度、实物信贷、战役方案，以及规则驱动的自主贸易、联区清算、利益冲突、禁运/有限战争与调停。完整新档节奏、更多谈判与联盟、完整金融银行仍待推进；这不等于全部设计已完成。原始存档、证据与跨电脑步骤见 HANDOFF。

## 本地启动

使用 Git 和 Node.js 24。项目当前无额外 npm 依赖。

```sh
git clone https://github.com/jiushiaaa/after_war.git
cd after_war/游戏
npm test
npm run dev
```

Windows PowerShell 如遇 `npm.ps1` 策略阻止，使用 `npm.cmd test` 和 `npm.cmd run dev`。浏览器打开 http://127.0.0.1:4180/ 。开发服务只监听本机。当前已在 Mac 验证，首次 Windows 接力需实跑测试和页面确认，不能假称已完成 Windows 实测。

## 目录

- `游戏/`：源代码、原 ADR 资源与许可、无依赖开发服务、自动化测试。
- `设计/`：全流程、科技树、经济社会政治和已实现规则；04—07为总体框架。
- `验证/`：自然游玩导出、验收记录和截图。原始存档不允许改写成实验状态。
- `HANDOFF.md`：最新检查点、下一步目标、跨电脑交接流程。

## 跨电脑继续

开始前确认另一台已停止开发并推送，再在仓库根目录执行 `git status`、`git pull --ff-only`。若有未提交改动或分叉，保留本地工作并先处理差异，不强制覆盖。

交班前完成相关验证，正常 UI 导出最新自然进度到 `验证/存档/`，更新 `HANDOFF.md`（当前提交、存档、已完成、未完成、测试、下一步），提交并推送 `main`。新机通过游戏正常存档入口导入该文件。浏览器 live、Codex 聊天、goal 和本机登录凭据不会随 Git 同步，不上传凭据。仅一台电脑同时推进主线。

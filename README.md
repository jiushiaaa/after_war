# 战后文明

直接基于 A Dark Room 官方源码的科幻废土文游。工作名未定稿。开局只有生火，随温度、物资、人口和设施自然展开；沿用原作地点、按钮、冷却、左侧记录、右侧库存和事件窗口。

## 本地运行

安装Node.js后在本目录执行 `npm run dev`，打开 `http://127.0.0.1:4180/`。不需要安装额外依赖；可用 `PORT=4181 npm run dev` 指定其他端口。`npm test` 运行规则与存档边界测试。

当前可玩：火/室温/工匠、采木采食、建屋与居民岗位、持续口粮和配给、稳定聚落、工坊研究、交通站/泵站、商队贸易、补给外站，以及发展解锁的2×、4×、8×和16×。农田、工具、健康、学堂、长屋、河谷独立库存与实物运输已接入。生火至河谷小镇的自然路径已通过。

小镇之后已有年龄组、出生/退休/寿终、领导者交接、四轴制度与行政支出，以及矿业—冶炼—机械—供电链。领袖更替保留建筑、技术、条约和库存。地区模块加入河谷、铁轨镇、高地收容所的独立人口和仓库、实际运输与返航、共同工程、加盟及公民资格。城市模块加入公共设施、两级住房、有限来源家庭迁入、80人正式镇制和400人首城持续供养条件，全部继续用原生地点、按钮、岗位与事件逐步展开。

已自然建成第一座城市“炉火城”，400人及连续300秒的供养/用电/公共工程门槛已实际走通。最新自然进度达到1164居民、24项技术和第十七任领导者；河谷登记镇制并扩至384床，独立货运与两组接纳旅队继续运行。人口计数、年龄与付费出生由本地、邻地、来源共享规则。

340项规则与存档测试通过。零本地成年恢复、来源留守与百年自供、跨年途中死亡、原来源返乡、跨来源旅队唯一性和损坏名册拒绝已有回归。市政完整设施的400人年龄夹具另通过100年供养与工业测试；另一份千人合成夹具经历100年年更、贸易和工业，1000→1560人、最低健康100、出生2204，教学始终覆盖。这两份长期实验是规则验收，不能写成自然第二城或三城3000。自然千人主城与三来源接纳另有原样存档和原生导入证据，见上层 `设计/08_开发与实玩记录.md`。

地方市政已接入：首城之后，经当地议约逐步建设田片、诊疗、学舍、住房与工业。建材由车队分批送到，当地成年人施工，地方人口、库存与供电分别结算；接纳计划可选择同意接纳的地方，来源、途中和目的地分别守恒。加固货车由原64容量货车运来材料、留地施工，再以128容量发新趟；施工与日常贸易共用车队。第二、第三座城市的80/400人门槛已有规则测试，浏览器自然扩建仍在推进，当前规则见设计18。钢、化工、玻璃与公用电站通过旧材料起步；药剂、水务田片、灌溉改造、160床密集住区和街区学校通过真实材料与成人施工展开。新旧工序共用当轮电力，水务只为下一次生产提供已付费的灌溉凭据；既有农田配方不被免费升级。规则详见设计20—23。

三个来源分别为河网散居圈（初始1800人）、旧城外缘（2000人）和山间聚居圈（1600人）。每处有自己的分龄人口、库存、生产、学舍、留守下限和有限迁出额度；未知来源同样出生衰老。新来源由当地两名实际成人自备旅粮联络480秒，本地20知识与来源10木料/10知识齐备才一起登记。Origins schema2只为合法旧档加入新模型，保留原河网全账，不补算新模型尚未存在的历史，不重发旧名册。详见设计24。

45742秒自然续玩档为重建76年、第十二任、主城1004/1004、河谷105/192、铁轨68/68、高地54/54。三座密集住区、两药房、三片水务田和街区学校已建成；20教师、16药剂师与1200人份供水实际运行。旧城累计41人已迁入，山间10人已迁入、8人在途赴河谷；已付协议、旅队和工程经原生导入继续。河谷与铁轨货车均已完成128容量改装，铁轨第二住宅在运料。44488秒新fixture保存联络尚余327秒的原始自然档，验证重载不会提前完成信使或重算人口。精确续玩文件与未完工程见设计08、10。

地方镇制与城市资格也认可近期实际交付的建设材料。建设、改装和公用工程共用货车时，不会只因暂未完成贸易回程就被认定断供；空车、取消返货和未到站材料不算交付。道路仍须开启、完好且有实际运输工；贸易完成次数不因此增加。

付费道路客运扩容已接入：历史首城与来源议约解锁“迁居运输组织”，研究后可建设最多两套迁居车组装备。每套实付木180、铁40、钢24、零件16、工具20，由两名实际营建工施工360秒；只增加两个运输岗位，不赠人口。大队最多24人、四名运输工，按三个家庭组选择真实儿童、成人和老人；每次在逐人旅费之外付木2、零件0.2、工具0.5。小队仍最多8人、两名运输工；不足条件会尝试小队，全世界仍最多两队。装备和运输工占用到返程结束，缺完整班组暂停移动。新快照锁定原始人数、实付与资产，旧8人名册原样保留；切换计划不能绕开发车间隔，付款后也须维持现有本地教学和诊疗。规则见设计25。原始双镇fixture为48712秒；另保留53708秒客运装备施工中原档，62秒实际工时重载不重算。自然首趟24人已由山间出发并到达主城，之后与8人小队交错运行；第十四任换届后主城1164、河谷224/288，另一批24人继续赴河谷。完整源账与装备已从正常入口恢复，原始下载38—43及截图见设计08、25。

界面按当前阶段收纳，沿用 ADR 原生地点与事件。右下角单一速度入口，城市与迁居运输解锁8×，第二座登记城市解锁16×；倍率统一推进生产、旅程、年龄与冷却。城市/市政改为概况与住房、供养、迁居等分类，人口来源、议事与工区也分摘要和明细；实际供水、药剂和用电门槛仍可查。地区关系图只画已发现节点和真实通路，点击继续进入原生地区协定窗口，尚非全球地理地图。

工坊出现后顶栏有“科技”，维修间有“打开科技”；可展开已掌握与直接下一层的真实前置、材料和试制时间，不展示文档中尚未实现的未来技术。原维修间已建满设施移入可展开记录，提高上限后可恢复到可建列。工匠原有自动守火保留每300模拟秒实付1木，城镇后旧炉按钮默认折叠，断木/熄火显示警报；修复不足1木扣成负数及熄火空耗。电站没有被当成免费集中供暖。

右下角“发展史”在有实际发展后出现，按任期、科技、镇制/城市、来源协议、竣工工程分页读取已有记录。原档未知日期明确标注；不补写虚假历史，不改变资源，也未声称已记录完整的历次制度改革。第16任、8×、河谷第3街坊住房已在原生UI实际续玩和导入，城市1164/1164、河谷333/384的64284秒原档留存；最新66998秒/第17任河谷已384/384，补充第6诊疗站完成，粮药净正与教学治疗恢复。早期3居民旧档另通过原样UI导入确认不会铺开后期页签。详细证据见设计08、10，新需求与未实现边界见设计27、28。

## 存档

本地预览没有平台宿主，只在本次页面中保存内存进度；右下角“存档”可导出JSON，重开后粘贴导入并确认替换。不要在未导出时刷新或关闭。

幻光宿主通过注入的 `window.LumiMakerSdk` 提供云存档；工程不手动引入SDK。启动必须先读，只有成功返回null才新开；失败停住，不覆盖原档。写入串行并合并等待期间的新进度。本地接口测试不等于真实平台验收。本项目没有发布到平台。

# 燧人 · Suiren

**从一团火，到重返星空。**

[网页版游玩](https://jiushiaaa.github.io/suiren/) · [Play in English](https://jiushiaaa.github.io/suiren/?lang=en) · [在幻光游玩](https://lumi.66rpg.com/works/4vkszlfyi9s0) · [幻光开源工程](https://lumi.66rpg.com/projects/4vli2ypu26m8)

战争之后，你从一间冰冷的维修间醒来。先点燃炉火，收集干柴，为敲门的人准备口粮与床铺；再修复道路、建设城市，联结失散的共同体，直到人类再次仰望星空。

《燧人》是一款渐进式科幻废土文字策略游戏，由 **旧石（jiushiaaa）** 创作与维护。基于 A Dark Room 的原生交互扩展：黑白文字、简单按钮、灰色冷却条与事件窗口，玩法随发展展开。玩家延续的是共同体；人物会老去，机构接过职责。

- **求生与探索**：守住炉火，经营聚落，带着有限补给进入有迷雾的近郊字符地图。
- **两条发展路线**：田地与公共服务，或回收与工业；不同生产顺序带来不同负担。
- **城市与共同体**：住房、就业、跨城运输、公共预算，以及地区间的法律、贸易与战争。
- **身体与未来**：基因技术、机械身体、合成人与生态恢复，能力变化伴随身份与权利选择。
- **重返星空**：统一地球，完成航天制造、生命保障与首航；本版不包含星际战争和旅行。

GitHub Pages 当前版本 **1.1.0**，支持简体中文与英语；幻光现有版本仍为 **1.0.2**。主线目标约 **12—15 小时**，可分多次游玩，实际时长仍在结合体验反馈校准。支持自动保存、暂停与倍率、夜间模式，以及随时代变化的音乐和环境声。已实现窄屏适配；真手机、iOS Safari 与读屏尚未完成全面验收，不将桌面模拟等同于移动版完成。

作品名取意于燧人氏传火。世界观与玩法灵感参考《这游戏也太真实了》《冰汽时代》《辐射避难所》《文明》《维多利亚》等作品；新增设定不代表原作官方内容。完整故事介绍见上方幻光作品页。

## 本地启动

使用 Git 和 Node.js 24。正常游戏运行与构建无需额外依赖；测试位置记忆、完整开发与文案工具请先安装声明的开发依赖。

```sh
git clone --branch main https://github.com/jiushiaaa/suiren.git
cd suiren/游戏
npm install --ignore-scripts
npm test
npm run dev
```

Windows PowerShell 如遇 `npm.ps1` 策略阻止，使用 `npm.cmd test` 和 `npm.cmd run dev`。浏览器打开 http://127.0.0.1:4180/ 。开发服务只监听本机。当前已在 Mac 验证，首次 Windows 接力需实跑测试和页面确认，不能假称已完成 Windows 实测。

### 分段体验与测试

开发服务启动后，打开 [体验测试入口](http://127.0.0.1:4180/test.html)。对应独立文件是 [游戏/体验测试.html](游戏/体验测试.html)，需要通过本地服务打开，不能只复制这一个 HTML 脱离仓库运行。

目录提供 37 个节点，按公共／工业路线、发展阶段或关键词筛选，再选择落地页面。覆盖新开局、近郊地图、城镇、万人城市、跨城物流、共同预算、地区国约、战争善后、先进身体社会、回响、地球账册、首航与结局；另有真实燃料和零件短缺现场。

每次“进入体验”都另开一个**独立测试副本**，先暂停。顶部可选页面后点“转到”，或继续运行、保存、导出、重来此节点。测试副本有独立本地存档槽与备份，刷新读取最近保存；目录可继续本浏览器的上次测试。测试页不读写正式存档或云存档，声音偏好也单独保存。除全新开局外，入口原件均为真实 UI 推进的验收档，不加资源、不替你完成研究或改变历史选择。

跨电脑时保留整个仓库的“游戏”和“验证”目录；测试中的新进度需自行导出文件。阶段体验不替代完整新档或真人时长验收。检查与限制见 [测试入口验收](验证/体验测试入口_验收.md)。

## 文案润色

完整稿、分卷和给Gemini的提示词位于 [文案编辑](文案编辑/Readme_文案说明.md)。先看 [阅读顺序](文案编辑/阅读顺序.md)，建议每次处理一卷，保留隐藏标记、占位符、数字和玩法含义。完整稿与分卷不要同时改；改好后将原始Markdown交回，说明“请把我改过的文案导入正式游戏”。来源映射和导出基线用于逐项审核，不是自动替换命令。

重新导出前先读文案说明；在“游戏”运行 `npm ci --ignore-scripts`、`npm run copy:export`，再运行 `node tools/check-copy-export.mjs`。尚有未导入改稿时不覆盖原稿；外部润色未收回时保留本轮基线，新导出放临时目录。只导出文字，不运行世界或改存档。

## 目录

- `游戏/`：源代码、原 ADR 资源与许可、无依赖开发服务、自动化测试。
- `设计/`：全流程、科技树、经济社会政治和已实现规则；04—07为总体框架。
- `验证/`：自然游玩导出、验收记录和截图。原始存档不允许改写成实验状态。
- `文案编辑/`：完整文稿、分卷、润色提示词、来源映射和导出基线。
- `HANDOFF.md`：最新检查点、下一步目标、跨电脑交接流程。

## 跨电脑继续

开始前确认另一台已停止开发并推送，再在仓库根目录执行 `git status`、`git pull --ff-only`。若有未提交改动或分叉，保留本地工作并先处理差异，不强制覆盖。

交班前完成相关验证，正常 UI 导出最新自然进度到HANDOFF指明的验证目录，更新 `HANDOFF.md`（当前提交、存档、已完成、未完成、测试、下一步），提交并推送当前工作分支（当前为 `main`）。新机通过游戏正常存档入口导入该文件。浏览器 live、Codex 聊天、goal 和本机登录凭据不会随 Git 同步，不上传凭据。仅一台电脑同时推进主线。

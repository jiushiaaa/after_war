# 战后文明

直接基于 A Dark Room 官方源码的科幻废土文游。工作名未定稿。开局只有生火，随温度、物资、人口和设施自然展开；沿用原作地点、按钮、冷却、左侧记录、右侧库存和事件窗口。

## 本地运行

安装Node.js后在本目录执行 `npm run dev`，打开 `http://127.0.0.1:4180/`。不需要安装额外依赖；可用 `PORT=4181 npm run dev` 指定其他端口。`npm test` 运行规则与存档边界测试。

当前可玩：火/室温/工匠、采木采食、建屋与居民岗位、持续口粮和配给、稳定聚落、工坊研究、交通站/泵站、商队贸易、补给外站，以及发展解锁的2×和4×。农田、工具、健康、学堂、长屋、河谷独立库存与实物运输已接入。生火至河谷小镇的自然路径已通过。

小镇之后已有年龄组、出生/退休/寿终、领导者交接、四轴制度与行政支出，以及矿业—冶炼—机械—供电链。领袖更替保留建筑、技术、条约和库存。地区模块加入河谷、铁轨镇、高地收容所的独立人口和仓库、实际运输与返航、共同工程、加盟及公民资格。城市模块加入公共设施、两级住房、有限来源家庭迁入、80人正式镇制和400人首城持续供养条件，全部继续用原生地点、按钮、岗位与事件逐步展开。

已自然建成第一座城市“炉火城”，历史来源检查点508本地居民、19项技术、第六任领导者。400人及连续300秒的供养/用电/公共工程门槛已实际走通；河谷共同治理、三条货运路线与两组接纳车队继续运行。河网散居圈作为独立的1800人来源已实际联络、付费议约，按原年龄名册迁入；保存时12人已抵达、8人在途。旧480名册与新来源分别守恒，正常重载不会重置来源。人口计数、年龄与付费出生由本地、邻地、来源共享规则。

250项规则与存档测试通过。零本地成年时以6粮逐人恢复、来源留守与100年自供、跨年途中死亡、返乡和损坏名册拒绝已有规则回归。市政完整设施的400人年龄夹具另通过100年供养与工业回归；这不是自然玩出的第二城。另一份完整付费设施的千人合成夹具通过100年年更、贸易和工业测试，1000→1560人、最低健康100、出生2204，教学始终覆盖；它验证实际结算与长期供养，不等于千人自然进度。正常首城、河网迁入及地方付费建设有未经人工改写的自然存档。证据见上层 `设计/08_开发与实玩记录.md`，实际规则见设计09、11、12、14、15、17、18。

地方市政已接入：首城之后，经当地议约逐步建设田片、诊疗、学舍、住房与工业。建材由车队分批送到，当地成年人施工，地方人口、库存与供电分别结算；接纳计划可选择同意接纳的地方，来源、途中和目的地分别守恒。加固货车由原64容量货车运来材料、留地施工，再以128容量发新趟；施工与日常贸易共用车队。第二、第三座城市的80/400人门槛已有规则测试，浏览器自然扩建仍在推进，当前规则见设计18。钢、化工、玻璃与公用电站通过旧材料起步；药剂、水务田片、灌溉改造、160床密集住区和街区学校通过真实材料与成人施工展开。新旧工序共用当轮电力，水务只为下一次生产提供已付费的灌溉凭据；既有农田配方不被免费升级。规则详见设计20—23。

自然续玩已到第九任领袖、本地524人、23项技术，河谷72人。三地田片、诊疗与学舍均已完成，河谷128容量货车实际运材扩建；钢、化工、玻璃和公用供电已运行。原样36765秒存档证明药剂师实际制药、600人份供水与第二水务站在建工期，已通过完整解码和浏览器正常导入；后续两站已达到1200人份供水，正在扩农业与住房。来源用自身材料和成人施工扩班至50教师席，未重置名册与迁出额度。精确续玩文件与未完工程见设计08、10。

尚未实现：完整财政与市场所有权、派系、军队与冲突占领、铁路与区域电网、城市群/国家/地球统一、首航结局。完整地球规格见上层设计04至06，城市群下一阶段见设计16。不要把原版遗留World/Space模块当成本作已实现的内容。

## 存档

本地预览没有平台宿主，只在本次页面中保存内存进度；右下角“存档”可导出JSON，重开后粘贴导入并确认替换。不要在未导出时刷新或关闭。

幻光宿主通过注入的 `window.LumiMakerSdk` 提供云存档；工程不手动引入SDK。启动必须先读，只有成功返回null才新开；失败停住，不覆盖原档。写入串行并合并等待期间的新进度。本地接口测试不等于真实平台验收。本项目没有发布到平台。
